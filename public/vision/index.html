视觉工作台使用指南

  1. 打开本地图像，或点击“演示案例”选择预设流程。
  2. 从工具箱点击或拖入算子，拖动节点自由布局；从输出端口拖到输入端口，或依次点击两个端口建立连接。
  3. 双击节点设置参数，在输入图像上绘制 ROI 或定位模板。
  4. 变量管理可查看和修改全局、流程、模块变量。Python 节点需要启用可信脚本执行。“执行所选”运行所选算子及其上游依赖；“运行流程”按连线依赖执行全部算子。
  5. 在模块结果表和日志中检查输出。保存工程后可再次读取。

实线传递图像/点云数据帧，虚线为执行依赖。汇合节点等待所有上游完成，可在参数区选择输入图像来源。预处理输出传给下游，识别节点保留输入图像。停止会在当前算子结束后生效。运行模式展示现有流程的操作画面。

已接入 USB UVC、GenTL、RealSense 和 Orbbec 单帧适配器及模拟设备；真实设备兼容性需现场验证。支持本地图像、点云文件和带内参的深度数据文件。点云仅在当前浏览器会话保留，工程保存算子配置；重新打开工程后需要载入数据。运行画面可在“画面组态”中添加组件、拖动布局、绑定变量及结果，应用后保存工程。

视觉演示案例

自动载入图像、模板与参数并运行。演示不会自动保存，可通过“返回原工程”恢复进入前的工作。

使用合成测试图演示算法；实际项目需用现场图像验证。

变量管理

全局变量跨工程共享；流程变量按工程 ID 隔离；模块变量按节点 ID 隔离。运行成功时提交，失败或停止时回滚变量。图像和设备外部动作不属于变量事务。

导入点云 / 深度图

支持 PLY、PCD、XYZ、XYZN、XYZRGB、PTS 和结构化深度数据文件。文件上限 12 MB / 20 万点。深度数据文件可以携带点云坐标，也可以携带深度数组和相机内参。

此处声明单位，不缩放原始坐标。文件内已声明的 unit 优先；参考点云文件沿用此处选择。数据与图像可同时保留在输入源中。

导入原始 16 位 PNG 深度图

只接受已校正针孔相机的光轴 Z 深度。需填写该文件分辨率对应的内参；普通灰度图、距离伪彩图和径向距离图不能用于此投影。导入成功后替换输入点云与深度，并清除原输入图像；文件不会随工程自动保存。

最多 12 MB / 400 万像素，采样网格最多 20 万点。输出毫米点云：X 向右、Y 向下、Z 向前；采样和预览不改变原始深度值。

工业通信

当前支持 Modbus TCP / RTU、西门子 S7、OPC UA 浏览读写、MQTT 消息发布/限时接收及 TCP/UDP/串口报文通信流程块。PLC 地址、站号、数据类型和端序在节点参数中设置；模拟验证不能代替实际设备验收。

Modbus TCP 本机模拟设备

仅监听服务器 127.0.0.1，动态端口，站号 1。四类地址空间 0–255；保持寄存器 0–2 初值 123、456、250。选“本机模拟设备”的节点会自动启动它。

OPC UA 本机模拟设备

仅监听服务器本机，提供计数、判定、浮点、文本及数组节点；Serial 节点只读。

西门子 S7 本机模拟设备

仅监听服务器本机。DB1：4096 字节；M / I / Q：各 256 字节。DBW0 初值 123，DBD4 的 float32 初值 12.5。模拟设备重启后恢复初值。

MQTT 本机消息服务器

Aedes 消息服务器仅监听 127.0.0.1 动态端口。支持 MQTT 3.1.1、QoS 0/1/2 和保留消息；停止后清空保留值。选择本机模拟设备的节点会自动启动。

TCP / UDP 本机回显设备

监听服务器 127.0.0.1 动态端口，原样返回收到的报文。模拟器不连接现场设备。

服务器串口

连续检测

服务器重复执行启动时的完整工程。每轮结束后等待设定间隔；关闭浏览器仍会继续。文件输入重复使用同一份数据，相机节点每轮重新采集。

执行成功轮次不等于产品合格数量。执行错误停止后续轮次；已完成轮次的变量保留。设备写入无法随取消回滚，服务重启后须手动重新启动。
