# 管理员发布与操作员运行（0.3.0 开发版）

开发/运行模式的视觉切换不能作为权限边界。新增独立操作员账户、服务器发布快照和运行入口，后台校验操作权限。现有开发工作台继续由管理员使用，旧发布包 0.2.0 不含此功能。

## 配置账户

部署配置保留一个管理员和一个可选操作员账户，另可在“帮助 → 账号管理”创建最多 100 个操作员账号，密码使用 bcrypt 哈希。管理员仍用 `ADMIN_USER` / `ADMIN_PASSWORD_HASH`；操作员用 `OPERATOR_USER` / `OPERATOR_PASSWORD_HASH`。两个用户名必须不同，启用操作员必须先设置管理员密码。不会内置或自动分配默认密码。

先用已安装的 `node-red admin hash-pw` 交互生成密码哈希，然后通过环境变量设置。Windows PowerShell 示例（将占位文字换成自己生成的完整哈希）：

```powershell
$env:ADMIN_PASSWORD_HASH = '<管理员 bcrypt 哈希>'
$env:OPERATOR_USER = 'worker'
$env:OPERATOR_PASSWORD_HASH = '<操作员 bcrypt 哈希>'
node scripts/platform.cjs configure --data-dir 'D:\SIEANS\runtime'
```

`configure` 保存两种账户配置，部署启动器从该配置设置运行环境；账号更改需重启服务。空的 `OPERATOR_PASSWORD_HASH` 环境变量可在下一次 `configure` 时禁用操作员。源码开发直接启动时读取环境变量；未配置管理员密码的本机开发实例仍为本机管理员模式，不能把它当作已验证的账户隔离部署。局域网继续要求管理员密码；远程 Basic 认证按现有部署说明置于 HTTPS 反向代理后。

备份恢复会保留两种账户的哈希和用户名、运行发布快照，并重写部署 Python/模型路径；归档仍包含敏感配置。新增操作员账号文件和有界操作记录随数据目录备份恢复。当前工作源码已加入 [网页登录与退出会话](web-login.md)，候选 4 冻结包不含该后续功能；外部身份系统及完整安全审计仍未实现。详见 [账号管理与操作记录](accounts-operations.md)。

## 发布方案

1. 管理员在开发工作台完成流程、参数、三级变量、画面和设备设置，**保存到服务器**。
2. 点击右上角“发布运行方案”，核对服务器保存工程的名称。
3. 如果工程或子流程含 Python 脚本，先检查源代码，再明确勾选允许执行可信脚本。未确认不能发布脚本工程。
4. 如需操作员连续运行，在发布表单勾选允许连续检测，并设定固定间隔和轮次（0 表示直到停止）。
5. 发布后打开对话框中的“操作员运行画面”，或直接访问 `/vision/operator.html`。

发布使用服务器已保存文件，未保存的浏览器编辑不参与。对话框读取的草稿指纹与实际发布时必须一致；其他客户端修改保存文件会拒绝发布，需刷新重查。运行期间禁止发布。发布快照固定流程、参数、参考数据、子流程、HMI 和脚本信任设置，后续编辑草稿不会改变已发布运行方案；更换方案需再次发布。

发布文件位于数据目录 `operator-publication.json`，原子写入并带内容完整性摘要。摘要是错误/意外修改检查，不是数字签名。管理员仍负责服务器文件、第三方插件及相同插件版本代码的维护；插件启用/缺失或依赖变化会影响执行预检。发布不是把设备驱动、模型或运行依赖一并打包。

## 操作员权限

| 操作 | 操作员 |
|---|---|
| 查看已发布 HMI 多页画面、数值、灯、图像、表格、报警及趋势 | 允许 |
| 运行已发布完整方案 | 允许，必须使用当前发布版本 |
| 连续检测 | 管理员在发布表单开放后允许，间隔和次数固定为发布设置 |
| 提供本次文件图像输入 | 允许；不修改流程参数 |
| 停止服务器当前手动、连续或 MQTT 触发执行 | 允许；等待已有运行取消/归档，不是硬件急停 |
| 写入已发布 HMI 的输入组件 | 允许，校验组件、类型、上下限、版本和变量修订号 |
| 确认已发布画面中的报警 | 允许 |
| 保存/导入服务端工程、改插件/相机/通信/训练/模型配置 | 拒绝 |
| 调用任意视觉、设备、脚本、工程任务或任意变量接口 | 拒绝 |
| 获取完整工程参数、脚本、未公开变量和未公开结果 | 不由操作员状态接口提供 |
| 发布新方案、读取发布草稿 | 仅管理员 |

操作员访问默认工作台入口会跳到独立运行页。后台权限不依赖隐藏按钮，直接请求管理员 API 同样返回 403。运行请求只接受当前发布版本和输入帧，不接受自带工程、目标模块、参数、脚本信任开关或变量集合。旧页面持有过期发布版本时不能继续执行或写入设定值；刷新后重新核对方案。

变量和结果只按管理员发布的 HMI 数据绑定投影给操作员；如果管理员把一个完整结构体、结果或整个变量范围绑定到画面，也会相应公开该内容。不要在面向操作员的结构体/错误/报警文字中放凭据。状态、运行错误和画面绑定的监控记录属于可见运行信息。

HMI 沿用同一个渲染器，支持页面跳转、未写入值保护、趋势暂停和报警确认。输入、执行、停止均走操作员专用接口。发布版本变更会重建画面并清除本浏览器文件输入和未提交输入；版本未变的轮询不会覆盖未提交设定。源码页未配置账户时，管理员也可用该入口预览权限受限的运行操作。

来源为“本次输入图像”的组件显示本浏览器选择的文件，跨客户端实时结果应绑定模块结果图；原始文件输入不因角色功能额外持久化。3D 可通过已发布采集流程和结果数值/表格运行，现已新增 [可交互点云组件](hmi-cloud.md)，只发送已发布绑定的有界预览。运行历史完整参数仍在管理员工作台查看，操作员页面主要显示当前发布方案的运行状态和组态数据。

## Node-RED 边界

配置管理员认证后，额外保护 Node-RED HTTP 运行入口及内置 FlowFuse Dashboard 的 Socket.IO namespace 连接，只允许管理员；仪表盘连接同时检查来源站点。原有未带凭据的外部 HTTP 调用需改为管理员认证或采用单独受控集成。编辑器仍使用 Node-RED 自己的管理员登录，不为操作员发编辑器权限。

这覆盖本项目启用的 Dashboard 与 HTTP 运行入口。管理员另行安装的任意网络节点、外部端口或第三方认证体系须单独评审；平台账户不是操作系统进程沙箱，可信脚本仍以服务账户权限执行。

## 验证

`npm run test:operator-access` 覆盖账户校验、不可变发布/信任门限、参数夹带拒绝、公开字段投影、HMI 范围/修订冲突、报警归属、忙碌保护、取消、服务重启和真实 HTTP/Socket.IO 连接。离线 DOM 行为测试复用全部 HMI 脚本验证输入写入、运行/停止、页面切换保护与方案更新；它不等于真实浏览器的视觉验收。

尚需新增页面可视、现场多客户端/代理配置、Windows 系统服务账户和 Linux 实机验收。

连续检测说明与验证范围见 [操作员连续检测](operator-continuous.md)。

操作员页面已支持通过表单导入本次点云文件，单位选择、预览与运行边界见 [操作员点云输入](operator-cloud-input.md)。

工作源码已修复本次图像文件的异步读取：读取期间阻止单次/连续启动，允许清除；切换发布方案、清除或重新选择文件后，迟到结果不能覆盖当前输入。读取失败或超限时保留旧预览，但必须重选成功或清除后才能运行。原始文件数值与点云仍分别遵循各自输入说明。验证：`npm run test:operator-image`。该修复未覆盖冻结的候选 3 ZIP。

候选 4 已纳入上述源码变更，独立安装与运行验证以候选 4 同名验收回执为准；候选 3 及更早的冻结 ZIP 不变。
