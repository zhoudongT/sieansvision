# 2D 采图质量检测

插件 `sieans-image-quality` 1.0.0 提供 `inspect` 算子，适合在定位、识别前进行采样质量判定。

原理采用 [OpenCV 官方拉普拉斯算子](https://docs.opencv.org/4.x/d5/db5/tutorial_laplace_operator.html)，项目源代码见 [GitHub OpenCV](https://github.com/opencv/opencv)。本插件自行组合灰度导数方差与亮度比例统计，未引入新依赖，也没有复制第三方源码。官方文档说明导数计算，本平台的阈值判定属于应用逻辑。

表单配置 ROI（宽高为 0 时延伸到图像边界）、最低拉普拉斯方差、过暗/过曝灰度阈值及允许比例。ROI 至少 3×3 像素；导数方差剔除外圈，避免边界补值影响，3×3 ROI 仅有一个导数采样，方差为零，应使用足够大的有纹理区域。曝光统计采用整个 ROI。

灰度小于等于过暗阈值计为过暗，大于等于过曝阈值计为过曝。清晰度大于等于下限、两个曝光比例小于等于上限时整体通过。过暗阈值必须低于过曝阈值。结果包括各项判定、整体判定和明细表，可绑定模块、流程或全局变量，用于后续流程条件。原图保持为下游输入。

灰度统计基于 OpenCV 解码后的 8 位灰度图。彩色局部通道饱和可能被灰度转换掩盖；本算子不代表相机原始位深的逐通道饱和检测。纹理、分辨率、曝光和噪声都会影响导数方差，噪声也可能增加分数。应在固定工件、镜头及采集设置下，用正常/异常样本确定阈值；不能用于通用自动对焦或保证后续识别正确。

演示库新增清晰、模糊、过暗、过曝四个案例，整体判定绑定到 `flow.captureOK`。验证命令：`node --test tests/test_image_quality.cjs`。两项测试覆盖四条真实 Python/OpenCV 流程、变量绑定、下游原图保持、ROI、矛盾阈值及边界。

当前旧预览服务需要正常重启以加载此插件；界面未加载时会显示不可用原因。实物曝光/对焦精度、Linux 和浏览器视觉验收尚未完成。
