# 参考点云偏差检测

`sieans-deviation` 1.0.0 的 `cloud-distance` 算子基于已安装的 Open3D，计算无符号最近采样点距离。算法来源：[GitHub Open3D](https://github.com/isl-org/Open3D)，语义依据：[官方点云距离说明](https://www.open3d.org/docs/release/tutorial/geometry/pointcloud.html#point-cloud-distance)。未复制第三方源码，沿用已有依赖。

输入点云需预先与参考点云配准，且坐标单位、坐标系一致。算子检查单位字符串一致，不自动校验坐标系或配准。输入上限 20000 点，参考表上限 1000 点；超过范围应先下采样。参考 XYZ 使用表格，可绑定流程变量、模块变量、全局变量或上游数组结果。

参数表单可设置最大距离、允许超差采样比例、双向检查及着色输出。默认双向：计算输入→参考及参考→输入；后者用于发现没有被输入点覆盖的参考区域。合格条件是全部参与方向的超差采样点数除以合计采样点数，不超过允许比例。采样密度不同会影响比例，双向不是两方向百分比取平均；请结合方向超差数量查看结果。

输出最大/平均/RMS 距离、方向超差数量、总体判定及最多 500 行超差明细。边界距离属于合格范围，数值舍入误差不计为超差。最多 10000 个输入点可输出红/绿着色；反向发现的缺失参考点不会出现在当前点云中，需要查看明细。统计仍包含全部允许输入点，明细截断不会改变判定。

它不计算带符号的曲面偏差、实体体积或缺陷类别。稀疏参考点、遮挡和不同采样间隔都可能造成距离增大。先用正常样本确定阈值；不能将本算子输出直接称为曲面尺寸误差。

演示案例新增：参考一致、整体高度偏移 2 mm、缺少一个参考点。参考表来自流程变量，合格判定绑定 `deviationOK`。

验证：`.venv/Scripts/python.exe tests/test_deviation.py`（4 项数值/异常测试）；`node --test tests/test_deviation.cjs`（真实 Python/Open3D 子进程执行三条演示、变量绑定和点云输出）。当前旧预览需正常重启后才会扫描到本插件；实物、Linux、局域网与界面视觉验收未包含在这些测试中。
