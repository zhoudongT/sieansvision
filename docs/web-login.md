# 网页登录、退出与会话（候选 4 之后的源码）

配置管理员密码后，浏览器打开工作台会进入 `/login`。使用已有部署管理员、部署操作员或平台管理的操作员账号登录；管理员进入开发工作台，操作员进入已发布运行画面。没有管理员密码的本机实例仍为开发模式，不创建默认账号或默认密码。

工作台顶部与操作员页顶部显示账号、角色和“退出登录”。退出撤销当前浏览器会话，多个标签页共用同一 Cookie；其他浏览器的独立会话不随之退出。退出或登录到期不停止已经受理的后台检测、训练或设备任务。需要停止生产任务时，先使用原有停止功能。

## 会话规则

- 无人工输入 30 分钟到期，最长 8 小时。鼠标、键盘、滚轮的可信用户事件节流更新活动时间；状态轮询、后台连续检测和普通接口读取不续期。服务器时间为准。
- 登录令牌只放在 HttpOnly、SameSite=Strict Cookie，服务端仅保留令牌摘要和有容量上限的内存状态，不写运行数据、工程、备份或浏览器存储。服务重启后重新登录。
- 退出、账号停用或密码更新后，旧会话不能继续访问 HTTP 接口。账号重新启用不会恢复已撤销的旧会话。已有受理任务不受影响。
- Cookie 会话的写入请求需要同源校验和独立会话校验令牌。网页自动添加，表单不显示令牌、Cookie 或后台数据格式。
- 登录失败使用统一提示；每个直连地址在 10 分钟内最多保留 10 次失败尝试，同时最多处理 4 个密码验证，最多保留 500 个会话。反向代理后的客户端可能共用地址，未直接信任客户端提供的转发地址。
- 登录到期返回登录页，不自动重放失败的写入或设备动作。未保存的工程编辑不会随登录跳转自动保存，开发时仍需主动保存工程。

## 兼容与部署

已有程序通过显式 Basic Authorization 调用 API 的方式保留；浏览器使用网页登录会话。浏览器登录后带有标记 Cookie，退出后不会因缓存的 Basic 凭据自动恢复工作台权限。旧服务未更新时，新会话前端不会显示虚假的退出按钮。

内置 Dashboard 接受管理员会话，操作员拒绝访问；已连接的会话失效后，连接会在约 1 秒内断开。Node-RED `/editor` 保持它原有的独立登录和令牌机制，本轮没有把它改成统一登录；退出视觉平台不会撤销 Node-RED 独立登录令牌。

实际 HTTPS 连接自动设置 Secure Cookie。HTTPS 反向代理终止 TLS、后端使用 HTTP 时，应在启动服务的环境中设置 `SIEANS_SESSION_SECURE=1`，并保留原始 Host；没有自动信任 `X-Forwarded-Proto`。局域网部署沿用已有 HTTPS 要求，不修改 VPN、路由或防火墙。

当前源码需要重启服务后生效，冻结的候选 4 ZIP 不包含该功能。不会自动配置或修改现有部署密码。本轮未重启原预览，也未发布或改写用户工程。

## 验证

`npm run test:sessions` 覆盖实际 HTTP 登录、Cookie 权限、同源/写入校验、退出与缓存 Basic 抑制、账号停用、重启失效、登录限流和 Dashboard；单元与离线页面测试覆盖空闲/最长到期、活动续期、口令清除和跳转。完整回归另存本轮日志；真实浏览器可视与下载、Linux 和现场设备仍按原清单待验。

会话与跨站请求防护设计参考 [OWASP 会话管理](https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html)及 [CSRF 防护](https://cheatsheetseries.owasp.org/cheatsheets/Cross-Site_Request_Forgery_Prevention_Cheat_Sheet.html)。这不代表完整安全审计通过；现有操作记录仍按其文档所列范围采集，不覆盖全部登录事件。

候选 5 已纳入上述功能，独立安装结果以候选 5 同名回执为准。当前运行的旧预览仍需另行更新/重启，打包不会修改它。


## 管理员查看与撤销会话（候选 5 之后的源码）

“帮助 → 登录会话”显示仍有效的会话表，包含用户、角色、公开会话编号、登录时间、最近人工活动和预计到期时间，标明当前浏览器；支持按用户名筛选、每页 50 条及手动刷新。该表是本次读取的快照，不是设备实时在线监测；关闭浏览器但尚未到期的会话仍可能显示。

点击一行“撤销”，核对用户和编号后再点击“确认撤销”；取消不会发送操作。撤销当前会话会返回登录页，其他会话不受影响；目标会话已到期或已撤销时提示相应状态。撤销仅使该会话失效，不停止检测、不禁用账号，账号持有人仍可用有效密码重新登录。永久禁止登录应使用原有账号停用功能。

后台列表和撤销接口仅允许管理员，Cookie 写入仍需同源/会话校验；明确的 Basic API 兼容规则不变。列表只包含公开元数据，不返回令牌、摘要、密码哈希、Cookie 或校验令牌；公开编号不能作为登录凭据。撤销请求进入原有操作记录，遵循其尽力记录与容量上限，资源编号为公开会话编号。新操作名称不保证旧版日志解析器可识别，回退沿用升级前数据备份。

旧服务没有声明管理能力时，页面隐藏该入口。此部分尚未加入冻结候选 5，也未更新当前 1919 预览；需要更新源码并重启服务。真实浏览器布局仍待验，自动化覆盖查询、选择/取消/确认、失败清除、自身退出和 HTTP 权限隔离。
