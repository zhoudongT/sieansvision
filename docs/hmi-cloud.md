# 运行画面的 3D 点云组件

0.3.0 开发源码的“画面组态”新增 **3D 点云窗口**，用于管理员运行画面与独立操作员运行页。组件绑定模块的输出 `cloud` 通道，不是结果字段或变量路径。图像、点云和数值窗口可以并排组态。0.2.0 已发布包不变。

## 组态与操作

属性表可选择模块、初始视角、点大小和最多预览点数。预览上限为 100–30000 点，点大小 1–6；视角为等轴、俯视或正视。显示单位、坐标系和检测 RGB 颜色，无颜色时使用 SIEANS 蓝色。

- 左键拖动旋转，Shift + 拖动平移，滚轮缩放。
- 画布聚焦后，方向键旋转、加减键缩放。
- 视角按钮复位到对应方向；Home 回到组态初始视角。

这是 Canvas 正交预览，不提供点位选取、透视渲染或量测工具。查看操作不会改变计算坐标、输入点云、参数或变量。编辑画布中关闭交互，避免拖动组件时同时旋转点云。

## 数据边界

计算继续使用完整数据，显示采用固定步长抽样，数量可能小于上限。窗口区分原始/显示点数；孤立点或局部缺陷可能未被抽中，不能以预览取代数值判定。全量边界用于适应画面，抽样点和颜色保持索引对应。

沿用 mm/m 单位、最多 200000 个输入点的契约；单点或共线数据也可预览。坐标、颜色无效时显示错误并清除旧图。当前节点失败、跳过或清空通道时不展示旧成功点云。翻页、关闭组态、切换方案会释放 ResizeObserver 和待绘制帧。

操作员仅收到已发布组件绑定的点云，服务器先按组件上限生成有界预览；同一模块有多个组件时，按最大上限发送，各窗口仍可再次限制。只公开点坐标、颜色、单位、坐标系、原始点数和预览边界，不因此公开模块的其他结果或点云自定义元数据。完整运行记录和后续计算数据不被抽样替换。

## 演示与验证

“演示案例 → 3D”的五个“倾斜基准/高度网格”演示增加点云、数值、状态灯和网格表，可查看合格、高度超差及采样/跨度无效点。保存并发布后，操作员页显示相同组件；草稿不会自行改变已有发布快照。

`npm run test:cloud-widget` 验证抽样、颜色、输入不变、投影/俯视层次、布局契约、操作员字段隔离、离线 DOM/Canvas、鼠标/键盘、通道清空和资源释放，以及实际 HTTP 发布、测量、保存与重启。

本轮 Computer Use 初始化后 `sky.list_apps()` 返回 native pipe unavailable（OS error 2），未取得真实窗口或截图；离线行为测试不等于真实浏览器视觉验收。新增界面可视、实际设备、节拍、大规模并发、GPU 点云和 Linux 实机仍待验证。
