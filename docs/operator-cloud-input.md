# 操作员点云文件输入

操作员运行页 `/vision/operator.html` 的“本次点云文件输入”提供文件选择、原始单位选择、导入按钮、元数据表和交互预览。支持 PLY、PCD、XYZ、XYZN、XYZRGB、PTS，文件不超过 12 MB，计算点云不超过 20 万点；不提供 JSON 编辑或任意算法调用。

1. 核对当前已发布方案。
2. 选择点云文件，明确选择文件原始单位 mm 或 m。
3. 点击“导入点云”，检查文件、计算点数、单位和坐标系表，以及可旋转/缩放的点云预览。
4. 点击单次运行，或使用管理员已开放的连续检测。

坐标数值不自动换算。选择 m 表示原文件数值以米为单位，并非把毫米数值除以 1000。文件没有坐标系声明时显示“未声明”；坐标变换、标定以及同时输入图像与点云时的对齐关系由工程流程保证，导入不建立两者的几何关系。

预览最多显示 12000 点，计算输入保留全部已接受点。导入数据只保存在当前浏览器页面，执行时送入已发布方案；连续运行在启动时复制文件输入，各轮重复使用同一份数据，相机节点仍按工程配置自行采集。刷新/关闭页面清空浏览器文件输入；跨客户端的可见计算结果仍由管理员 HMI 绑定决定。导入本身不写工程、变量或运行历史；执行时是否保存原始帧遵循工程历史设置。

选择新文件或改变单位后，需要重新导入或清除文件输入才能启动。导入失败保留上次成功数据，并明确提示新选择未生效；发布方案变更时清空文件输入，迟到的导入结果被丢弃。“清除文件输入”同时清除本次图像和点云。

后台专用接口只接受当前发布版本、文件名、内容和单位，固定调用点云解析器，不接受客户端指定操作、参数、脚本或服务器文件路径。导入期间保留运行资源，阻止其他作业/发布插入；解析预算为 15 秒，超时沿用共享视觉引擎重置行为。它不是生产作业，解析期间的停止请求会提示等待；关闭请求不保证取消解析，但解析结束或失败会释放保留资源。导入请求记录用户名和请求结果，不记录文件名或文件内容。

验证：`npm run test:operator-cloud`。覆盖表单单位选择、完整输入与有界预览、改变选择的启动保护、失败保留、发布变更、后台字段拒绝、资源保留/释放，以及实际 Open3D 导入→单次 3D 测量→连续检测→操作记录。离线 DOM 验证不代替真实浏览器视觉验收。

当前功能在工作源码与开发预览；冻结的 candidate 3 ZIP 保持不变，不含此后续入口。
