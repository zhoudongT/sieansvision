# 局域网监听与账号验收

`npm run test:lan` 是显式指定网卡的隔离验收入口，不随默认 `npm test` 启动。它创建临时运行目录、随机测试密码和临时端口，只绑定指定网卡；不修改已有部署、工程、发布方案、防火墙或 VPN。

先用系统网络设置核对本机已分配的 IPv4 地址。PowerShell 示例中的地址须替换为本机地址：

```powershell
$env:SIEANS_TEST_HOST = '192.168.1.100'
$env:SIEANS_LAN_REPORT = Join-Path (Get-Location) 'artifacts/my-lan-acceptance.json'
npm run test:lan
```

地址必须是本机已分配的非回环 IPv4，不接受 `127.0.0.1`、`0.0.0.0` 或任意远程主机。回执文件必须尚不存在。默认使用当前源码的依赖与 Python；验收已解压安装的候选包时，将 `SIEANS_RELEASE_ROOT` 设置为其程序目录。此入口在候选 4 冻结后加入源码，不在候选 4 ZIP 内；可从当前源码调用，并指向候选 4 的独立安装目录。

检查范围：网卡地址 HTTP 连接、匿名/错误密码拒绝、管理员工作台、操作员页面跳转、开发接口隔离、平台操作员账号、发布画面运行，以及两个操作员账号读取同一计数结果。流程只增加临时变量，不调用相机、PLC、机器人或用户脚本。完成或失败均请求关闭自身启动的服务，检查运行锁释放；临时数据目录保留供诊断。

通过也仅证明同一主机经网卡地址访问，不能代替第二台设备、真实浏览器、HTTPS 反向代理、现场网络及 Linux 验收。失败退出码为非零；不要把服务器成功监听等同于 HTTP 可达。
