### 2. 「图像采集」信息架构（三课统一）

```
图像采集
├── 图像源  ← 本系列核心
│   ├── 本地图像   「从本地图像中加载图像」
│   ├── 相机取图   「从已配置的相机中获取图像」
│   └── SDK        「通过VM二次开发获取图像」
├── 多图采集
├── 输出图像
├── 缓存图像
└── 光源
```

> **实现要点**：画布上通常只拖一个 **「图像源」** 节点；三种取图方式是该节点属性里的 **「图像源」下拉**，不是三个独立算子。

### 3. 交互流程（添加算子）

1. 点击左侧分类图标 → 展开该分类下的算子列表（或直接拖默认算子）。
2. **拖拽**算子到流程画布 → 自动命名：`{序号}{算子名}{实例号}`，如 `0图像源1`、`1快速匹配1`。
3. 底栏日志：`添加模块: 流程1.图像源1`。
4. 未配置完整时节点带 **红色叹号**；配置完成显示绿色状态点。
5. **双击节点** → 打开该模块的属性浮窗（核心交互，本地图课字幕明确：「双击图像源…」；匹配课：「双击快速匹配模块」）。

## 流程画布（拖拽、连线、运行）

### 1. 画布外观

- 深灰 **点阵网格**。
- 顶部 Tab：**流程1**、**流程2**… 与 **+** 新建流程。
- Tab 旁流程级控件：**运行流程 ▶**、**循环**、刷新/设置。
- 画布右下角：**小地图（minimap）** + 缩放百分比（状态栏亦有缩放滑条，如 100%）。

### 2. 节点形态

- **胶囊/圆角矩形**；左侧小图标 + 文案 `序号 + 名称`。
- **选中**：橙色描边。
- **端口**：节点上下/侧边有可连线圆点；默认执行流为 **自上而下箭头**（橙色/绿色）。
- 典型演示链：
  - `0图像源1` → `1快速匹配1`
  - `0图像源1` → `1快速匹配1` → `2位置修正1` → `4DL字符识别…`
  - SDK 嵌入控件示例：`图像源1` → `快速匹配1` → `位置修正1` → `字符识别1` → `格式化1`

### 3. 连线规则（改造需实现）

- 拖放新节点到已有链下方时，常自动接在上一节点输出。
- 图像数据通过 **「输入源」下拉** 显式选择，如：`0 图像源1.图像`（见快速匹配「基本参数」）。
- 删除/重排后序号可重排（节点前缀序号）。

### 4. 运行

| 入口 | 行为 |
|------|------|
| 全局工具栏「单次」 | 整方案/`SyncRun` 一次 |
| 全局「连续」 | 循环跑 |
| 流程 Tab 旁 ▶ | 跑当前流程 |
| 属性浮窗底栏「执行」 | 只跑当前模块（调参即时预览） |
| 属性浮窗「连续执行」 | 当前模块连续 |
| 属性浮窗「确定」 | 关闭并保留参数 |
| 图像列表「运行全部」 | 对本地图列表逐张跑流程 |

执行后状态栏刷新：`流程 xx.xxms | 工具 xx.xxms | 算法 xx.xxms`。

## 属性/参数面板（含输入输出）

### 1. 浮窗通用壳

- 标题：`{序号} {模块名}`，如 `0 图像源`、`1 快速匹配`。
- 深色标题条 + 右上角 **X** 关闭。
- **图像源**：单页分组滚动（无多 Tab）。
- **快速匹配**：顶栏四 Tab：
  1. **基本参数**
  2. **特征模板**
  3. **运行参数**
  4. **结果显示**
- 底栏按钮（匹配类）：**连续执行** | **执行**（主按钮橙） | **确定**；左下角可有重置图标。

### 2. 控件规范

| 类型 | 表现 | 出现处 |
|------|------|--------|
| Toggle | 胶囊，ON 橙 OFF 灰 | 几乎所有布尔项 |
| 下拉 | 激活时橙边框 | 图像源类型、像素格式、触发源… |
| SpinBox | 上下箭头；大范围时常带 **下方滑条**（如图片缓存） | 缓存、分数、角度… |
| 绑定钮 | 输入右侧小图标 → 绑全局变量/他模块输出 | 取图间隔、曝光、字符… |
| 条件显隐 | 父 Toggle ON 才展开子字段 | 拼接使能→起始/拼接高度；字符过滤→输入/触发字符 |

### 3. 「0 图像源」完整字段（本地模式）

#### 基本参数

| 标签 | 控件 | 示例/取值 | 说明 |
|------|------|-----------|------|
| **图像源** | 下拉 | `本地图像` / `相机` /（SDK 语境） | 三种取图模式切换 |
| **像素格式** | 下拉 | `MONO8` / `RGB24` | 黑白 Mono8，彩色 RGB24 |
| **取图间隔** | Spin + 绑定 | `0` | 相邻两张加载间隔 |
| **方案存图** | Toggle | 默认关 | 开则把本地图写入方案；**最多约 120 张**；落盘临时目录类路径如 `...\Temp\VM*ImgSrcTemp\` |
| **显示图像名称** | Toggle | 默认开 | 视口显示文件名 |
| **SN初始值** | Spin + 绑定 | 如 `1192` | 运行后帧号起点，作结果标记 |
| **图片缓存** | Spin（+滑条） | `0`~`5` 常用 | 测试时预载本地图到内存 |
| **输出Mono8** | Toggle | 可选 | 强制输出 Mono8 |
| **拼接使能** | Toggle | 关 | ON 后展开下列子项 |

**拼接使能 ON 时展开：**

| 标签 | 说明 |
|------|------|
| **起始高度** | Y 方向裁剪起点 |
| **拼接高度** | 拼接后保留高度 |
| **触发清空** | 触发时清空拼接缓冲 |

拼接语义（课中原文意）：两张图沿 **Y 方向依次拼接**，再按参数裁剪输出。

#### 触发设置

| 标签 | 控件 | 说明 |
|------|------|------|
| **自动切换** | Toggle | 跑完自动切下一张本地图 |
| **最后一张停止** | Toggle | 切到最后一张后停止（自动切换开时常见） |
| **字符触发过滤** | Toggle | ON 后展开： |
| → **输入字符** | 文本 + 绑定 | 选择输入字符来源 |
| → **触发字符** | 文本 + 绑定 | 相等才触发流程；不等则不触发 |
| **触发变量** | 绑定 | 可绑「全局变量」等 |

### 4. 「0 图像源」相机模式增量字段

当 **图像源 = 相机**：

| 标签 | 控件 | 说明 |
|------|------|------|
| **关联相机** | 下拉「请选择」+ **相机图标按钮** | 点图标进 **相机管理** |
| **控制曝光** | 输入/绑定 | **必须为 Float**；可手输或绑变量 |
| **控制增益** | 输入/绑定 | 同上 Float |
| **SN初始值** | Spin | 同本地 |
| **输出Mono8** / **拼接使能** / **字符触发过滤** | 同结构 | 拼接子项同本地 |

未选相机时：状态栏红字示警示例：`0 图像源1 组件参数未配置完整`。

### 课 02 — 相机取图

**目标**：图像源切到相机，经「相机管理」连设备并控曝光增益。

#### A. 图像源侧

| 步 | 操作 |
|----|------|
| 1 | 双击图像源 → **图像源 = 相机** |
| 2 | **关联相机** 点右侧 **相机图标** → 打开 **相机管理** |
| 3 | 选好全局相机后回到属性；绑 **控制曝光/控制增益**（Float） |
| 4 | 执行流程取流；可在结果区看帧号/丢帧 |

#### B. 相机管理窗（模态）

布局：左 **设备列表**（**+** 添加） | 右 Tab **常用参数** / **设备控制** | 底 **确定**

**添加相机类型**（点 + 后弹窗「请选择添加相机的类型」）：

- **全局相机**
- **Dalsa图像采集**（Camera Link + Dalsa 卡）
- **迈创采集**

设备命名示例：`4 全局相机1`

#### 常用参数 · 相机连接

| 标签 | 控件 | 说明 |
|------|------|------|
| **GenTL相机** | Toggle | |
| **类型选择** | 单选 **枚举** / **跨网段IP** | **优先推荐枚举**（直连） |
| **选择相机**（枚举） | 下拉 + 刷新 | 如 `Hikrobot MV-CS050-10GC (G883…)`；未连可为 `Close` |
| **本机IP**（跨网段） | 只读/自动 | 一般不改 |
| **相机IP** | 四段 IP 框 | 跨网段远程枚举 |
| **连接相机** | Toggle | |
| **连接状态** | Toggle/指示 | |
| **自动重连** | Toggle | |
| **图像缓存数量** | Spin（默认可 50，可至 100） | 硬触发时防丢帧；对比本地缓存常约 5 |
| **实时取流** | 按钮/开关 | **仅组播相机支持** |
| **断线重连时间** | Spin ms（如 100） | |
| **软触发超时** | Spin（如 2） | |

#### 常用参数 · 触发设置

| 标签 | 取值 |
|------|------|
| **触发模式** | 含 `Off` 等；Off 时部分项灰显 |
| **触发源** | `LINE0`/`LINE2`=**硬触发**；`SOFTWARE`；`Counter0` |
| **触发延迟** | 数值 |

#### 常用参数 · 图像参数 / 增益 / Gamma

| 分组 | 字段 |
|------|------|
| **图像参数** | 图像宽度、图像高度、像素格式(Mono 8)、帧率、实际帧率、曝光模式、曝光时间 |
| **增益** | 增益、增益模式(CONTINUOUS…)、最小增益、最大增益 |
| **Gamma** | Gamma使能 Toggle、Gamma 值、选择器(USER) |

课中强调：上述可在 VM 内完成，**无需再进 MVS 客户端**。

#### 运行参数（设备侧）

| 标签 | 取值 |
|------|------|
| **相机类型** | `标准面阵相机` / `智能相机` / `线阵相机` |
| **有效电平** | `高电平有效` / `低电平有效`（常配合 IO 通讯；线阵语境下出现） |
