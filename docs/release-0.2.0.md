# SIEANS Vision 0.2.0 源码安装版

0.2.0 汇总流程/HMI、工业通信、相机连接和 2D/3D 算子的近期开发成果。交付形式仍为源码 ZIP 加在线安装，不包含 Node.js、Python、模型、设备驱动、运行数据或离线依赖缓存。完整平台仍按 [实施清单](platform-roadmap.md) 推进，版本号不表示所有现场硬件已经验收。

## 主要能力

- 拖拽流程、自由连线、条件/错误分支、子流程和有界循环；Python 自定义脚本，模块/流程/全局变量。
- 多页运行画面、表单输入、结果表、趋势/报警、服务器连续检测及历史记录。
- Modbus、S7、OPC UA、MQTT、TCP/UDP/串口流程块；MQTT 持续订阅、有限消息队列、工程事件触发。
- 单帧相机及持续 SDK 连接，单帧缓存、新帧等待、过期检查、停止释放和有界重连。适配器覆盖 UVC、GenTL、RealSense、Orbbec；实际设备与厂商 CTI 仍需现场验证。
- OpenCV/ZXing/OCR、YOLO 检测/实例分割；棋盘格相机内参标定及畸变校正。
- Open3D 点云处理、配准、平面/球面/圆柱检测，已知对应点坐标标定与正反向转换、独立点验证。
- 插件参数、点位表和变量绑定采用功能表单/表格；后台模型及工程结构化保存。

## 安装、更新与停止

需要 Node.js 24.x、Python 3.12.x，以及安装所选依赖所需的网络访问。安装、访问控制、模型目录和系统服务模板见 [部署说明](deployment.md)。先执行 `node scripts/platform.cjs verify`，再使用安装工具；新版本解压到独立程序目录，运行数据保持在程序目录之外。

更新前停止原服务并备份整个运行数据目录及另存的模型目录。新版本先用备份副本验证工程/插件/设备配置，再切换生产数据。当前不提供自动数据迁移、一键回滚或兼容性保证；回退时使用旧程序和更新前的数据备份，不直接混用新版本写入后的数据。

启动器给自有服务 45 秒停止时间，服务模板为 60 秒，覆盖相机最长 30 秒读取及释放阶段；超过总上限才强制结束自有子进程。服务停止会取消等待作业、回滚未提交变量并释放相机/MQTT。参数写入、PLC 写入或已发送消息属于外部动作，不会回滚。

旧版生成的 WinSW/systemd 模板仍保留原等待时间。新模板需另行生成、检查并由维护者更新服务配置；本版本不会自动修改或安装现有系统服务。当前也未对系统服务进行实机验收。

## 发布完整性与验证入口

包内 `release-manifest.json` 包含发行文件摘要。相同源码可重复产生相同 ZIP；生成器拒绝覆盖内容不同的同名包/校验文件，同内容重建不改写原包。SHA-256 用于完整性验证，不代替发布者身份签名。

源码目录运行 `npm run check` 和 `npm test`。新包在独立环境安装后可执行下面的发布验证，使用包内的 Python，而不是开发目录的虚拟环境：

```powershell
$env:SIEANS_RELEASE_ROOT = 'D:\SIEANS\SIEANS-Vision-0.2.0'
$env:VISION_PYTHON = 'D:\SIEANS\SIEANS-Vision-0.2.0\.venv\Scripts\python.exe'
$env:SIEANS_DEPLOY_TEST_FULL = '1'
node "$env:SIEANS_RELEASE_ROOT\tests\test_deployment_http.cjs"
```

该测试在临时运行目录启动自有服务，覆盖版本/依赖、2D/3D、内参/坐标标定插件、模拟 Modbus/相机/深度、持续相机会话、MQTT 事件、多页工程保存、数据持久化、取消回滚及启动器退出。它不访问真实 PLC/相机，不等于现场设备验收。

Linux、真实工业/体积相机、硬件同步、长期压力、真实 PLC、YOLO/深度 SDK 的本次独立安装、GPU和新增界面视觉验收均需单独记录。当前开发机没有已安装的 WSL 发行版或 Docker 可用于 Linux 运行测试，Windows 结果不能替代 Linux 证据。
