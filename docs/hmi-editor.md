# 运行画面组态

开发预览增加 [3D 点云窗口](hmi-cloud.md)：绑定模块输出点云，配置预览点数、点大小和初始视角；管理员与操作员画面均可旋转、平移、缩放。预览抽样不替代计算或数值判定。

工作台以表单配置参数、以表格定义变量和查看结果。脚本保留 Python 代码编辑区，输入参数和输出变量映射使用表格。工程与布局在后台采用结构化数据存储，操作界面不要求编辑原始数据格式。

## 使用

1. 打开“演示案例”，运行“组态运行画面 · 相机数量检测”。示例使用模拟零件相机，检测到 3 个轮廓。
2. 点击“画面组态”。左侧添加或选择组件，拖动组件标题移动位置；右侧表单设置位置、大小、样式及数据绑定。
3. 点击“应用画面”，再“保存工程”。取消编辑会丢弃本次布局草稿。
4. 切换“运行模式”，或打开 `/vision/?mode=run`。有布局时显示组态画面，没有布局时保持原图像/结果面板。
5. 在示例的“目标数量”输入 4，点击“写入”，再“运行检测”。数量仍为 3，判定变为“未通过”。输入值修改后必须点击写入。

## 组件与绑定

| 组件 | 设置或数据来源 |
|---|---|
| 文本 | 固定标题、字号和颜色 |
| 数值显示 | 全局/流程/模块变量、模块结果字段或运行状态；精度和单位 |
| 状态指示灯 | 布尔字段；通过、未通过、未知三种状态 |
| 图像显示 | 当前浏览器输入图像或指定模块输出图像 |
| 结果表格 | 数组和对象；嵌套数据展开成表格，最多显示 100 行、20 列 |
| 操作按钮 | 运行当前流程、停止当前作业或跳转到指定页面 |
| 变量输入 | 全局/流程/模块的顶层变量；数字、文本或布尔，数字可设范围 |
| 报警 | 阈值、回差、稳定样本与确认；事件以表格显示 |
| 趋势 | 数值采样曲线与明细表，失败或无效样本显示缺口 |

绑定使用来源、模块和字段控件。嵌套读取字段以点分隔；变量写入只允许顶层名称。模块被删除后，相关绑定应重新选择；缺失数据按未知显示。判定灯仅将布尔值视为通过/未通过，避免把缺失结果当作成功。

每页采用 12 列网格，4–40 行、行高 40–120 像素，最多 50 个组件；整个工程最多 20 页、200 个组件，报警与趋势组件合计最多 50 个。拖动按网格吸附，宽高通过属性表单修改。编辑预览中的操作按钮和变量写入不执行动作。布局随工程保存，不单独发布。多页面的新增、复制、排序、默认页和导航见 [多页面运行画面](hmi-pages.md)。

## 运行与多浏览器

运行开始立即清除上一轮显示，状态变为运行中；执行期间禁止修改画面变量和重复启动。另一浏览器加载同一已保存工程后，每秒查询最近一次作业和当前变量。未提交输入不会被轮询覆盖；当前后台值和“待写入”提示分别显示，提交使用变量版本检查。

布局编辑保存后，其他浏览器需要重新载入工程或刷新页面；自动同步的是运行数据，并非编辑草稿。通过浏览器打开的源图像属于本地输入，其他浏览器应绑定服务器作业产生的模块输出图像。

服务器仅在内存保留最近 3 个作业，按工程 ID 选择最近作业。失败或取消不会回退展示旧成功结果。服务器重启后作业结果清空，持久化变量保留。运行视图不是历史归档或实时订阅服务。

工具栏现支持 [服务器连续检测](continuous-runtime.md)。连续任务的每轮结果更新到 HMI；等待下一轮时也锁定变量输入。HMI 停止按钮会停止整个连续会话，刷新后通过“连续检测 → 查看运行工程”可重新载入配置快照。

局域网访问沿用工作台现有认证与监听设置；运行模式目前不是独立操作员权限。多页面及服务器报警/有界趋势已实现，详见 [报警与趋势](runtime-monitor.md)。权限分级、专用长期趋势数据库和 HMI 内 3D 视口仍待实现，3D 查看仍在开发工作台。作业历史另见 [运行历史归档](continuous-runtime.md#运行历史归档)。

## 验证

- `npm run check`：前后端脚本及节点编辑器检查。
- `npm test`：50 项 Node 测试、11 项 Python 2D 测试，以及 HTTP/插件/HMI 与 Node-RED 条码集成验证通过。其中 7 项覆盖布局验证、字段读取、网格移动、工程隔离、版本增量和作业状态。
- 浏览器：拖动与属性坐标同步、组件标题修改、应用布局；目标数量 3/4 的通过/未通过切换；双客户端变量及结果同步、未提交输入保护，以及保存后刷新恢复布局。

上述验证使用本机 Windows 和模拟相机，不表示已完成现场设备或 Linux 部署验收。
