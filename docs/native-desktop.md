# 原生桌面开发版

更新：2026-10-24。界面使用 PySide6 / Qt Widgets 原生控件；算法运行时通过标准输入输出与独立 Node 进程通信，复用已有算法、插件、相机与通信后端，不启动 HTTP 或 Node-RED 服务。

## 启动

在仓库根目录、已安装原有 Node/Python 算法依赖的环境执行：

```powershell
.venv/Scripts/python.exe -m pip install -r desktop/requirements.txt
.venv/Scripts/python.exe -m desktop.main
```

Windows 开发版打包：

```powershell
./scripts/build-native.ps1
```

输出：`artifacts/native-desktop/SIEANSVision/SIEANSVision.exe`。保留同目录 `_internal` 和 `runtime-root.txt`。该构建复用本机仓库中的 Node、`.venv`、插件与算法文件，**不是可以单独复制到其他电脑的完整安装包**。移动仓库后需重新打包或用 `--root` 指定运行环境。

可使用 `./scripts/build-native.ps1 -BuildName native-migration` 生成独立验收构建，避免覆盖正在打开的旧程序。打包时自动同步网页端声明的算子目录，原生表单另做类型与结构化字段适配。

默认数据保存在当前用户的应用数据目录。`--data <目录>` 可指定独立数据。不要让网页服务与原生程序同时写入同一目录。原生版不自动恢复旧网页相机连接；从相机页面明确连接后，关闭页面保持连接，退出程序释放自身设备与子进程。

## 本轮完成范围

- 原生菜单、工具栏、可调整宽度的工具箱、流程、参数和图像区域。
- 算子工具箱采用分类图标网格，提供类型图标、折叠分类、搜索、完整名称悬停提示；双击图标添加模块，也可直接拖入流程。
- 流程模块拖放、移动、多选、复制粘贴、撤销重做、自动布局和自由连线；支持分支/汇合，禁止循环依赖。支持按住上下/左右端口拖到目标端口后松开，也可依次点击连接；可以从输入端口反向拖到输出端口。连线时显示预览与目标高亮，Esc 或拖到空白处取消；缩小时端口保持可见并使用屏幕像素命中范围。
- 插件清单发现、按定义生成原生参数表单、输入/输出绑定表格、结构化结果表格。界面不展示原始 JSON 或脚本源码。
- 本地图像与模板参考图、真实算法执行、执行所选模块及其依赖、取消、图像和耗时结果。
- `.sieans` 工程保存与打开，兼容读取现有工程文件；未迁移的工程附加字段保留。输入图像需重新加载，模板参考图随模块保存。
- 合成工件轮廓演示，无需连接相机。工具箱加载 37 个内置算子及当前仓库的 44 个插件算子，共 81 个入口；可显示不等于所有算法都已逐项验收，模型与依赖仍需按对应说明安装。

## 演示工程库

工具栏“演示工程”已接入原网页 **31 份清单、149 个案例**，沿用同一份本地素材与案例定义，不依赖网页服务。分类、搜索、预览、说明、预期结果和依赖提示采用原生表格与表单。

- “仅载入工程”打开图像、模板、点云、深度、参数、连线、变量与组态定义；“载入并运行”在满足条件时自动执行。
- “返回原工程”恢复进入演示前的工程、未保存修改、撤销重做历史、剪贴板、输入数据和已有结果。切换多个案例仍保留最初备份；演示不会自动保存。
- 深度案例可在“深度图”页查看伪彩预览、完整原始分辨率与单位；点云裁剪不裁剪原始深度栅格。
- 含 Python 脚本、缺少模型权重或标为事件触发的案例只载入。脚本仍需显式可信执行；权重不会自动下载。禁用插件有明确提示。
- 原生端重映射结果引用、HMI 绑定、子流程内部节点和条件连线，使用独立工程编号；模拟相机会话仅在明确载入对应案例后启动，不替换已有其他设备连接。
- “仅载入当前算子的示例数据”复用原网页的工件、条码、文字或点云样例。

31 份原清单保持不变。149 项已逐项载入并校验工程与素材，实际执行测试覆盖代表性 2D/3D、条件、子流程/循环、HMI、插件、深度及七种本机模拟通信；这不等于全部案例和所有真实设备已逐项验收。部分演示本身用于展示失败分支或类型错误，需按“预期结果”判断。

## 旧工程与权限

从原网页导出工程，或使用原数据目录中的工程文件，在原生“文件 → 打开工程”读取后另存为 `.sieans`。模板参考图随工程保存，单次输入需重新加载。原插件、模型、Python 依赖与相机 SDK 仍按原配置路径使用。

程序不会自动复制原服务历史、全局运行变量、账号或训练数据。迁移数据目录应先停止原服务并备份；不能只复制 EXE 就获得这些内容。

沿用 `ADMIN_USER` / `ADMIN_PASSWORD_HASH`。配置凭据后，原生引擎要求管理员登录；未配置时为本机开发模式，不能新增受管操作员。审计不记录密码或脚本内容。目前账号管理可以维护操作员账号，但操作员独立登录和受限运行尚未迁移；HMI 预览不等同于生产发布。

## Linux 启动（本机 GNOME / Wayland）

工程后续以 **原生桌面 App（PySide6）** 为主，不再依赖网页连续预览。

```bash
cd /home/allen/文档/sieansvision
# 完整工作台（流程 / 相机 / 连续采集）
./scripts/start-linux-desktop.sh

# 仅相机满速连续预览（GenTL → QLabel，无浏览器、无 OpenCV HighGUI）
./scripts/start-linux-live.sh
```

注意：

- U3V USB 独占：网页 Node-RED、MVS Client、live 预览、桌面工作台同一时刻只开一个。
- 本机缺 `libxcb-cursor0` 时 PySide6 的 `xcb` 插件会失败，启动脚本默认 `QT_QPA_PLATFORM=wayland`。
- 桌面「连续连接」预览读的是会话一帧 PNG 缓存（约十几 fps）；要接近相机满速用 `start-linux-live.sh`。
