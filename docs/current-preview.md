# 当前源码预览副本

入口：[http://127.0.0.1:1920/vision/](http://127.0.0.1:1920/vision/)。原 `1919` 服务继续保留。

1920 使用当前工作源码，已加载操作记录 CSV、网页登录/会话接口、管理员会话管理及 GenTL 16 位 XYZ 格式选项。当前为本机开发模式，没有设置或复制账号密码；需要账号认证的功能仍须按[网页登录说明](web-login.md)配置认证实例。

启动时只从原数据目录复制已保存工程和已发布方案，不复制账号、运行变量、历史、触发状态、Node-RED 流程或模型。新实例使用源码自带的手动 Node-RED 示例，没有自动检测/订阅/采集任务。模型目录独立，依赖模型的工程需另行准备模型。

继续在 1920 编辑、保存或运行会写入副本目录 `artifacts/current-preview-1920-data`，不会自动同步回原 `artifacts/hmi-pages-preview-data`。原工程和历史仍在 1919；新副本里的计数、变量与历史重新开始。

来源摘要与复制范围在副本目录 `preview-provenance.json`；启动验收为 `artifacts/current-preview-1920-acceptance.json`。HTTP 确认新功能接口与静态资源可访问，原 1919 健康且工程/发布文件摘要不变；没有真实浏览器视觉验收，也没有进行相机采集。

由 `scripts/preview-host.cjs` 管理它自己启动的子进程，不接管原服务。它提供本地监督进程的 status/restart/stop 命令，没有新增远程重启接口。当前存活的执行句柄记录在验收文件，后续操作必须先确认句柄和运行状态。
