# 三级变量与固定类型

变量管理始终使用值表格和类型选择表单。后台保存结构化工程数据，不要求操作员编写或修改 JSON。

## 定义与使用

1. 打开“变量管理”，选择“工程初始定义”，新增流程或模块变量并设置初始值。
2. 在该作用域的“类型约束”表中选择固定类型，应用定义后保存工程。默认“动态（不限制）”保留已有工程行为。
3. 在“运行当前值”中查看和修改数值。全局变量及全局固定类型在这里设置，点击“写入当前值”一并保存；它们由服务器共享，不随单个工程导出。
4. 在算子参数中绑定变量，或通过变量节点、Python/插件输出绑定写入。运行平台在每个节点之后检查类型，错误会停止后续节点。本轮尚未提交的变量变更全部回滚，保留上次成功保存的值。

支持有限数值、安全整数（±9007199254740991）、文本、开关、数组、结构体、空值，以及数值/整数/文本/开关数组。固定数组元素类型时可使用空数组，但不能混合其他元素类型。数值允许整数；整数不接受小数。文本“3”、数值 3 和开关“是”互不自动转换。单一“数组/结构体”类型目前只约束容器，尚未约束内部字段结构；嵌套内容仍受有效值、深度和大小校验。

类型定义的变量名使用字母或下划线开头，后续为字母、数字、下划线，最多 64 字符，不能使用保留字。动态变量沿用既有规则。

## 初始值、当前值与调整

- 流程和模块的固定类型必须有匹配的工程初始值；初始值及类型分别随工程和节点保存。没有类型字段的旧工程保持动态行为。
- 已保存的运行值优先于初始值。修改初始值不会覆盖上次运行值；如果新类型与已保存值冲突，启动前直接报错，不执行节点。仍可打开变量管理修正当前值。
- 手动删除流程或模块当前值会恢复工程初始值。脚本删除具有固定类型的变量则报错，不能在当前轮次中临时违反定义。全局固定类型变量没有工程初始值，必须先明确解除类型约束才能删除。
- 全局类型持久化在服务器变量存储中，其他工程写入同名全局变量也必须符合类型。写值请求省略类型信息不会取消现有全局约束。只有显式编辑并提交全局类型表才能改变它；修改仍受运行锁和变量修订号冲突检查。
- 返回的结果未提交并不代表外部设备动作已撤销。此前已经发生的 PLC 写入、脚本文件操作等不能由变量事务回滚；本功能不实现权限或安全沙箱。当前工程的流程/模块定义随提交工程采用，不能据此作为跨客户端权限控制。
- HMI 变量输入同样经过服务器校验；类型错误时显示原因。工业读值经变量节点绑定时亦遵守约束。Python 的变量范围替换和插件输出映射均受检查。

## 演示与证据

“演示案例 → 流程”提供：

- **固定类型变量 → 检测数量**：检测 3 个轮廓，流程整数 count=3、开关 accepted=是，模块开关 done=是。
- **固定类型变量 → 拦截错误赋值**：第二步把文本“3”写入整数 count，流程停止，第三步不执行，count=0、accepted=否。将赋值改为数值 3 可通过。

8 项新增 Node 测试覆盖所有类型、退化定义、初始值、持久化、跨工程全局约束、旧存储兼容、手动/HMI 写值、真实 Python、插件输出绑定、停止下游与回滚。HTTP 验证工程类型往返保存、运行赋值、错误写值不增加修订号，以及跨工程全局约束。默认 `npm test` 和 `npm run check` 纳入验证。

## 界面展示约定

- 参数依据所选功能显示对应表单；坐标、数组、结构体使用表格。
- 变量总览列出作用域、名称、类型、初始值、当前值和校验状态。
- 脚本源码保留代码编辑器；输入参数、输出绑定和运行结果使用表格。
- 脚本和插件输出绑定表同时显示实际类型及最近输出值；数组、结构体、结构化文本按表格展开。尚未运行、字段缺失、失败或跳过分别提示，不把空值、数值 0 或开关“否”误报为缺失。输出预览不等于变量已提交，持久值在变量管理中核对。
- 脚本参数页的“脚本全部返回字段”展示结果字段、实际类型和返回值，包含未绑定变量的结果；源码独立编辑，输入参数、输出绑定与运行数据使用表格。普通运行日志中的有效结构化文本也按字段展开，底部状态栏保留说明并提示查看日志。
- 结果的第一层表格默认展开，嵌套内容按需展开，大表每批展示 50 行。
- 脚本日志及历史日志采用序号、内容类型、内容表格；完整对象/数组，包括带说明前缀或跨行打印的有效结构化数据，解析后按字段展示，原始日志仍保留在后台。普通文本、无效或不完整数据保留为文本，避免丢失诊断信息。
