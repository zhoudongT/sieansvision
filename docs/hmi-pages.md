# 多页面运行画面

运行画面支持工程内多个页面，用于生产概览、趋势、报警和参数设定。页面和组件属性均通过表单配置，结果、变量与报警使用表格；无需在操作界面编辑原始存储格式。

## 编辑与运行

1. 打开“画面组态”，设置运行画面总标题，选择要编辑的页面。
2. 使用新增、复制、删除、页面前移/后移和设为默认页。页面自己的标题、网格和组件独立设置。复制会生成新的组件身份，报警与趋势不会共用原组件的记录。
3. 在组件属性中选择目标页面并点击“移动组件到页面”，可以保留组件身份搬移；其报警和趋势记录不会因此重建。目标页空间不足时先调整尺寸。
4. 添加操作按钮，将动作设为页面跳转，再选择目标页面。其他页面仍有跳转按钮引用的页面不能删除，需先修改相关按钮；最后一个页面不能删除。
5. 点击“应用画面”并保存工程。取消关闭会丢弃本次布局草稿。模板仅替换当前页。
6. 运行模式通过顶部页面标签或页面内的跳转按钮切页；切页只改变当前浏览器的显示，不启动流程、不写变量，也不停止正在运行的连续检测。

每页最多 50 个组件，整个工程最多 20 页、200 个组件，报警与趋势组件合计最多 50 个。旧单页工程可直接加载，打开组态编辑后转换为多页文档，原有组件身份保持不变。

页面选择按工程保存在当前浏览器标签会话中，各客户端独立。链接 `/vision/?mode=run&page=overview` 可指定页面（`overview` 是演示页的标识）；无有效选择时采用默认页。复制、删除和组件身份是工程配置，其他客户端需刷新才能加载修改后的布局。

## 输入与后台监控

当前页面存在未写入或正在写入的变量时，切页会被阻止，避免丢失输入。先点击“写入”，或点击“放弃未写入值”恢复服务器当前值，再切页。重复点击运行模式也不会清空当前未提交输入。

服务器遍历工程所有页面的报警与趋势组件。隐藏页面不停止采样；关闭浏览器不停止已启动的服务器连续检测。采样时机和保留策略沿用 [报警与趋势](runtime-monitor.md)，切页、刷新和只读轮询不会生成采样点。页面重命名、排序以及保留组件身份的移动不会重置监控历史。

页面标签角标统计该页面组件中“仍活动或尚未确认”的报警事件，同一事件只计一次；确认仍活动的报警后，角标仍保留，直到条件恢复。角标不是该页面全部历史报警数。

## 演示与验收

“流程控制 → 多页面运行画面 · 切页与后台监控”包含生产概览、温度趋势、报警记录和参数设定四页，每轮温度 +2；模拟温度达到阈值且满足稳定样本条件后产生报警。

- `npm run test:hmi-pages`：9 项模型/监控单元测试和 HTTP 集成；覆盖旧单页转换、身份/导航校验、容量上限、复制/删除、跨页监控、角标计数、保存失败不覆盖、后台连续检测、只读访问、排序/default 修改和真实服务重启恢复。
- 相关运行时、变量、流程、子流程、历史、连续任务、报警及 HMI 回归共 112 项通过；`npm run check` 通过。
- Windows 浏览器已验证导航按钮、未提交输入保护与放弃、运行中切页、双客户端独立选择、复制/移动/删除/排序/default、保存重启、趋势样本与报警角标。验收工程增加“维护参数”第五页用于组件跨页搬移测试。

当前不包含操作员角色、页面访问授权、专用长期趋势数据库、HMI 内 3D 视口或 Linux/现场硬件验收。源码旧发布包不会自动包含本次修改，正式发布前需重新构建并验证新包。

## 开发预览

`node scripts/preview-host.cjs 1919 artifacts/hmi-pages-preview-data` 启动仅本机监听的开发预览。启动命令的标准输入支持 `status`、`restart`、`stop`；重启只通过 IPC 关闭该监督进程自己创建的服务子进程，等待其退出后使用原端口和数据目录启动。停止超时不会启动替代进程。

此工具不提供远程关闭接口，不附加其他 PID，也不代替正式的系统服务安装和部署流程。部署入口见 [部署说明](deployment.md)。
