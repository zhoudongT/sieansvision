# 账号管理与操作记录

开发工作台“帮助 → 账号管理”可创建、停用、重新启用和重置操作员密码，最多 100 个。管理员及部署配置中的操作员仍由部署配置维护，平台新增账号只能是操作员；界面不支持修改用户名或删除记录。需要先配置管理员密码，未配置时只显示本机开发模式，不允许新增账号。现有工程和运行发布快照不因账号管理而改变。

密码至少 12 个字符，最多 128 个字符且 UTF-8 不超过 72 字节，不允许控制字符。服务端保存 bcrypt 成本 12 的哈希，账号列表不返回哈希。保存采用新文件与原子替换，失败保留原账号配置。账号文件损坏时停止启动，保留文件供管理员修复。启用、停用与密码重置在下一次认证请求生效，不能撤销已经进入执行的请求或停止已启动设备动作。仍使用 HTTP Basic，浏览器可能缓存旧凭据；没有登录会话、注销按钮、密码找回、自动锁定或外部身份系统。局域网认证继续按部署说明配置 HTTPS 反向代理。

“帮助 → 操作记录”仅管理员可读，用表格按用户、操作、请求结果和时间查询，每页 50 条。记录工程保存、插件启停、变量写入、运行方案发布、操作员执行/连续启动/点云导入/停止/输入/报警确认、开发流程启动/取消、连续检测、MQTT 触发、连续相机、训练启动/取消，以及新增/修改操作员账号。账号修改记录包含账号资源编号；不记录密码、脚本、输入参数值、图像、请求头、查询字符串、原始响应或原始错误。

每条包含时间、用户名、角色、开发模式标记、操作类别、可用的路径资源编号、HTTP 状态、请求耗时和结果。HTTP 202 标记“已受理”，不代表作业执行成功；HTTP 2xx 的其他状态仅表示请求成功，异步任务的最终结果请看运行历史。4xx 标记请求被拒绝，5xx 为服务端失败，响应完成前连接关闭为连接中断。认证后的权限拒绝会记录；匿名认证失败、Node-RED 编辑器部署、脚本内部动作、外部应用动作及连续执行的每轮内部步骤不在本记录范围内。

操作记录保留最近 5000 条或 4 MiB，达到任一上限时淘汰最早记录。列表查询不生成记录。文件损坏或写入失败会停止追加、保留原文件，并在查询页显示警告与本次启动漏记数量；已经完成的操作不因此撤销。它是有界、尽力写入的平台操作历史，不是不可篡改、保证持久性或合规用途的完整审计。没有清空或删除 API。

数据目录新增 `operator-accounts.json` 和 `operation-history.jsonl`，离线备份恢复会携带它们。归档包含账号哈希，仍属敏感配置；恢复到新实例后沿用账号，必须保留管理员密码配置。备份请使用现有停机与数据目录锁流程。

验证：`npm run test:operations`；账号校验、密码更新、禁用、并发更新保护、重启持久性、权限隔离、记录过滤/分页/保留上限、坏文件保留、写入失败及敏感信息排除。离线 DOM 测试覆盖表格筛选和账号表单；不等同于真实浏览器视觉验收。当前改动在工作源码与开发预览，未覆盖此前冻结的发布 ZIP。

工作源码的部署工具已增加账号文件与部署用户名/管理员密码的一致性检查，拒绝会导致下一次启动失败的账号配置。`doctor` 可只读查看账号数量及操作记录文件警告；详见 [部署预检](deployment.md)。旧冻结候选包未覆盖此后续修复。

## 操作记录 CSV 导出（候选 4 之后的源码）

在“帮助 → 操作记录”设置用户、操作、结果和时间条件，点击“导出筛选结果 CSV”。导出请求开始时匹配的全部已保留记录，最多受原有 5000 条/4 MiB 保留策略限制，不限当前显示的 50 条分页；不导出已经淘汰或漏记的记录，也不表示完整安全审计。空结果导出表头。

CSV 使用中文表头、UTF-8 BOM、UTC 时间和最新记录优先顺序，可作为表格文件打开。内容包含编号、用户、角色、开发模式、操作、请求结果、资源编号、HTTP 状态与耗时；沿用字段白名单，不包含密码、脚本、输入值、图像、文件名或请求正文。文本中的逗号与引号按 CSV 转义，可能作为表格公式执行的开头文本增加单引号前缀。

后台 `GET /api/vision/operations/export` 仅管理员可用，接受与列表相同的非分页筛选条件，不接受 offset/limit，响应禁止缓存。记录存储异常时返回失败，避免把不完整存储导出成看似正常的空表。该 GET 导出请求不新增操作记录。

当前功能需要加载新版服务器源码后生效。前端只在服务器声明 CSV 能力后显示按钮，旧服务仍可正常查询。冻结的候选 4 ZIP 不包含该功能。相关单元/界面与 HTTP 角色测试覆盖全筛选结果、UTF-8、公式文本、错误状态和权限，真实浏览器下载仍待验。

当前源码加入 [网页登录、退出和会话](web-login.md)：账号停用或密码更新同步撤销其网页会话。部署账号、Basic API 和 Node-RED 独立登录的差别及重启生效要求见该说明。

候选 5 包含网页会话与 CSV 导出，独立安装结果以同名回执为准；旧候选 4 ZIP 不变。
