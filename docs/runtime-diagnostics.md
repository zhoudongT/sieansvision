# 运行诊断与隔离压力验证

“帮助 → 运行诊断”提供手动刷新的只读表：服务器版本/平台/运行时长、Node RSS/堆/外部内存、事件循环启动以来活跃比例、作业缓存、视觉队列/进程、Python 脚本/插件进程、工业通信进程、相机占用、MQTT/TCP/UDP 任务、连续任务及历史容量。

后台 `GET /api/vision/diagnostics` 只允许管理员读取；操作员沿用默认拒绝策略。数据使用明确字段白名单，不返回工程、脚本、变量、图像、设备地址、认证配置或完整服务状态。管理员接口包含自有进程 ID，供验证退出后是否仍存在；界面使用表格，不展示传输格式。

进程计数在子进程 `close` 后减少，取消请求返回时，计数可能短暂非零，直到资源实际关闭。相机占用是平台资源锁数量，包括持续采集会话；视觉引擎通常有一个常驻 Python 进程，空闲不等于应为零。工业通信进程计数不包括 Node 内实现的 MQTT/TCP/UDP，它们分别显示任务数。

**内存只统计 Node 服务器进程，不含 Python、SDK、GPU 或整机内存。** RSS 波动、内存分配缓存和垃圾回收都会影响数值，不能从一张诊断表推断泄漏；未提供实时 CPU、完整设备健康度或长期资源数据库。事件循环比例为进程启动以来的累计指标，不能解释为当前 CPU 使用率。读取失败清除旧表，避免继续显示上一次数值。

## 可重复的压力入口

在项目已安装依赖的目录执行：

```sh
node scripts/soak-runtime.cjs --cycles 220 --warmup 20 --report artifacts/my-soak-report.json
```

命令创建临时数据目录、空 Node-RED 工程和独立本机服务器，自动选择动态端口。仅使用模拟持续相机和本机 Modbus 模拟器，不连接当前预览或真实设备、不更改当前保存工程。结束后通过自有 IPC 关闭它创建的服务器，检查已记录的自有常驻子进程是否退出，保留临时目录便于复核。不会停止未知进程。

每轮通过新帧采集 → 真实 OpenCV 数量 → 亮度插件 → Python 三级变量累积 → Modbus 写/读 → 故障守卫。每 10 轮注入脚本失败，每 25 轮注入执行中取消（该轮优先取消），验证流程/模块/全局变量提交或回滚；设备外部写入不宣称回滚。检查每轮结束的相关资源计数、缓存最多 3 条、历史最多 200 条及字节预算、趋势最多 20 点和报警确认。完整输入不写入历史，以免把图像归档吞吐当作此场景的压力结果。

默认 220 轮、20 轮预热后检查 Node RSS 增长预算 256 MiB，可用 `--max-rss-growth-mib N` 调整。轮次范围 5–10000，预热必须小于轮次，内存增长预算 16–4096 MiB。预算是本次验收阈值，不是内存泄漏的判定算法。回执必须是新文件，拒绝覆盖；参数、成功/预期失败/取消数量、逐轮内存、上限和清理结果均写入回执。意外错误或超过预算返回失败，不把它记作注入的预期失败。

`npm run test:diagnostics` 验证字段隔离、真实 Python 取消后计数、诊断窗口刷新/错误清空和操作员拒绝访问；`npm run test:soak -- --cycles 220 --warmup 20 --report 新文件` 可运行完整入口。常规 `npm test` 包括诊断单元/行为验证，不自动启动 220 轮压力任务。

这类有限合成运行只建立重复验证基线，不能替代 24/72 小时现场运行、Python/原生 SDK/GPU 总内存、真实相机丢帧、PLC 断线、真实模型、所有协议/算子组合、数据库写盘故障或 Linux 实机验收。当前新增诊断窗口还需真实窗口可视验收，冻结的 0.3.0-dev-candidate-2 ZIP 尚未更新。

## 本机实际记录

2026-10-16 Windows 验证共 220 轮，用时 158.69 秒，194 正常、18 注入故障、8 主动取消；20 轮预热后的 Node RSS 基线 104.45 MiB，后续最高 136.13 MiB，增长 31.68 MiB。未以此推断长期无泄漏。历史实际保留 200 对数据/摘要文件，逐文件长度及 SHA-256 校验通过，无临时文件残留，趋势保留 20 点。220 轮回执中的 `camera` 是停止前状态，不能将其中 running 当作退出后状态；该次清理断言及服务器退出检查均通过。

另运行 30 轮，包含 26 正常、3 注入故障和 1 取消，回执增加明确的相机停止前后及最终资源快照：相机 stopped、相机占用/脚本/工业进程/活动插件均为 0，随后自有服务退出。对应证据为 `artifacts/runtime-soak-220.json`、`runtime-soak-cleanup-30.json`、`runtime-soak-storage-check.json`。本次不是 Linux、现场设备或长时间压力验收。
