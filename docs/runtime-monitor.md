# 服务器报警与趋势

“画面组态”新增报警列表与趋势曲线组件。与其他组件一样拖动布局，使用属性表绑定流程/全局/模块变量、模块结果或运行状态；参数不需要编辑配置文本。运行模式的工具栏可打开“报警与趋势记录”，查看当前工程的报警、确认备注、趋势系列和采样表。组件预览不产生采样或确认。

## 采样与状态

服务器在每轮手动作业或连续检测结束后采样；变量写入也采样变量绑定，结果/状态绑定不因变量写入重复采样。全局变量变更会更新其他已注册工程中的全局绑定，不误采样其局部绑定。浏览器读数、刷新、暂停显示或关闭不会生成额外样本，也不会停止服务器连续采样。监控配置随下一轮作业或变量写入启用；绑定/阈值等配置变化会结束旧配置事件并重建相应状态，历史表标明“配置停用”，不冒充现场恢复。改变位置、大小、字号和颜色不重置状态。

这里是事件驱动采样，时间轴为实际采样时间，不是固定周期采集卡。连续检测按原有轮次间隔运行；每个作业内的中间算子结果不单独采样。长作业内部变化、周期内瞬态信号、未接入平台的外部变量变化不会被捕获。

## 报警

支持数值大于/大于等于/小于/小于等于、保持类型的相等/不等、布尔是/否。可选提示/警告/严重级别。大小比较提供恢复回差；高报警激活后用“阈值减回差”判断维持，低报警用“阈值加回差”，比较符号仍按原来的严格/包含边界规则执行。连续确认样本数为 1–100，发生和恢复均需达到该样本数；这是样本计数，不是毫秒延时。缺失/无效数据清空待确认计数，但不会清除已经发生的报警，界面标明数据未知并保留原状态。

每次真正从正常转为报警生成一条事件，记录组件、级别、触发值、发生/恢复/确认时间、结束说明和可选确认备注。确认不会消除仍存在的报警条件；恢复与确认分别记录，已经恢复但未确认的事件仍可确认。确认操作按工程和事件编号定位，同一事件重复确认不重复修改。触发文本最多保留 500 字并标记截断，备注最多 200 字。当前使用现有工作台访问认证，没有增加操作员实名/签名或合规审计功能。

作业失败/取消时，变量和结果绑定的数据作为未知处理，不用旧值伪造新的有效采样或清除报警；运行状态绑定仍可针对 failed/cancelled 触发报警。未激活或失败节点的结果也不会复用上一轮值。

## 趋势

趋势仅接收有限数值；缺失、布尔、文本、非有限数值、失败/取消结果记为缺口。曲线在缺口处断开，孤立有效点仍可见；采样表保留时间、值、数据质量和原因。支持单位、小数位数、每系列保留 20–1000 点；界面显示当前配置保留样本数。组件或记录窗口的“暂停显示”只冻结浏览器查看，恢复后读取服务器最新样本。

每工程最多保留 5000 个趋势点和 200 条报警事件，超过后移除最旧趋势点与最旧已结束事件（可能仍未确认）；显示移除计数。整个服务最多保留 20 个监控工程，优先淘汰最旧的无活动报警工程；全部旧工程仍有活动报警时拒绝新工程监控并给出错误，保留原报警。存储上限 16 MiB，文件为独立数据目录中的 runtime-monitor.json，以临时文件替换方式写入。它不是长期历史数据库；过保留期、配置重建和工程淘汰的样本不自动恢复。最新事件、确认、恢复和曲线在服务重启后读取，重启本身不补造采样。

监控写盘失败不撤回已经完成并提交的算子变量；作业/运行画面显示监控错误，运行历史保留警告。连续检测停止后续轮次，已经成功完成轮次的变量保留，避免在监控失效后无提示地持续运行。确认、读取失败会给出错误，不静默显示成功。

## 验收

`npm run test:monitor` 包含 15 项测试：阈值/回差/确认、未知质量、低/布尔/状态报警、趋势缺口、配置更换、样本/事件/工程保留、全局跨工程绑定、作业回滚、写盘失败及连续停止、取消、重启、作用域与异常数值绘图。HTTP 验收在没有浏览器的情况下连续运行 10 轮，验证确认后条件仍报警、另一个客户端状态更新、恢复、失败缺口、只读轮询不采样，以及真实服务退出后重启恢复。

演示“流程控制 → 运行画面 · 服务器报警与趋势”每轮温度 +2。运行模式中可观察趋势；连续检测建议 10 轮。阈值为 ≥12、回差 2、确认样本数 2；可先确认仍存在的报警，再在温度设定值写入 0 两次，观察恢复和确认独立记录。演示值为软件变量，不是实际传感器测量。

[多页面运行画面](hmi-pages.md) 已接入：未显示页面的报警与趋势仍由服务器采样，切页与只读轮询不会添加样本；页面标签显示活动或待确认报警数量。专用趋势数据库、外部消息持续订阅、周期采样器、操作员角色和审计仍需后续实现与现场验收。
