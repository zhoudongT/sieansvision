# SIEANS 三维圆柱检测 1.0.0

独立 Python 插件提供自由轴圆柱拟合与基准侧面偏差检测，用于已分割的轴、管件、滚轮点云。功能参数、模型、变量绑定和检测明细均以表单/表格显示。通过通用 `machine-operator` 节点也可在 Node-RED 中使用。

依赖沿用 `vision/requirements-3d.txt` 的 NumPy 与 SciPy 1.18.1；插件代码使用 MIT，SciPy 的 BSD-3-Clause 及发行依赖说明保留在 `third_party/scipy/LICENSE.txt`。Windows 已验证；Linux、实际相机点云与测量精度仍需现场验收。

## 圆柱拟合

1. 输入声明 `mm` 或 `m`，所有长度阈值沿用输入单位。需要至少 12 个独立点，重复坐标不重复参与拟合与内点比例计算。
2. 按固定种子对独立点均匀抽样，默认最多 3000 点，可设 12–10000 点。使用中位原点与尺度归一化改善大坐标、小尺寸情况下的数值稳定性。
3. 以三组 PCA 方向分别初始化，投影圆估计初始半径与轴点。优化变量是两个轴向倾角、两个垂直于轴的偏移与一个半径；轴向允许变化，不要求工件轴线对齐坐标轴。
4. 稳健模式使用 SciPy `least_squares` 的 `soft_l1` 损失，再按径向内点阈值进行最多 8 轮几何最小二乘/重新分类。普通模式使用全部采样点的几何最小二乘。选择采样内点最多、内点均方误差最小的收敛候选。
5. 对最终雅可比计算条件数，检查方向搜索边界；对全部独立内点检查周向覆盖角与轴向跨度/半径比。默认要求条件数不超过 100、周向覆盖至少 120°、轴向跨度至少为半径的 0.5 倍。退化、覆盖不足或优化不收敛时输出 `found=false`、`passed=false` 和说明，不输出伪造的零轴点、直径或模型。
6. 对全部输入点重新计算径向误差。独立内点比例、内点 RMS 和直径公差同时满足时才 `passed=true`。可靠拟合但直径超差时 `found=true`、`passed=false`，模型可供诊断或后续算子使用。

模型轴向是单位向量，最大绝对分量规范为正；轴点取拟合轴上最靠近独立内点质心的点。轴点不是工件端点，沿轴移动轴点或反转轴向不会改变同一个无限圆柱。`sampledAxialSpan` 仅是观测内点沿轴投影的跨度，不能当作完整工件长度。

该算法是有限多初值的局部优化，不是 RANSAC、全局最优保证或场景中多个圆柱的自动分割器。应先使用裁剪、滤波、聚类选出一个目标。条件数和覆盖阈值用于拒绝明显不稳定的拟合，不是精度证书。

## 圆柱侧面偏差

`cylinder` 基准可以在模型字段表中填写，也可绑定上一步结果或三级变量。模型标识 `sieans-cylinder-v1`，字段为轴点 `axisPoint`、单位轴向 `axisDirection`、正半径 `radius`、单位 `unit`、坐标系 `frame`。输入点云与基准的单位和坐标系必须完全一致；不会隐式缩放或配准。轴向长度偏差超过 `1e-6` 时拒绝使用，不能输入零向量。

每个点的偏差为“点到轴线的垂直距离 − 半径”，向外为正、向内为负。公差下限/上限与最大超差百分比控制判定。最小/最大偏差、峰谷差和 RMS 按所有输入点计算；点位表同时报告原始索引、XYZ、轴向坐标及是否超差。位于轴线上的点偏差为负半径，也纳入检测。

模型描述**无限圆柱侧面**，不检测端面、不测量完整长度、不计算实体体积，也不代表标准最小区域圆柱度。对当前工件自拟合再检查适合查看局部形状偏差，会吸收整体尺寸和姿态变化；绝对验收应使用独立基准并单独检查直径。

## 输出和资源边界

- 保留输入点序、坐标、单位和坐标系。拟合时绿色为内点、红色为离群点；偏差检查时绿色为公差内、红色为超差。可靠拟合但直径超差的点仍可为绿色，合格与否以结果判定为准。无法拟合时全部灰色。
- 颜色输出最多 10000 点；更大点云需关闭着色或先下采样。输入上限 20 万点，拟合采样上限 10000。统计覆盖全部点，不只统计抽样点。
- 明细最多 500 行，可选择全部点或仅离群/超差点；截断时返回 `detailsTruncated=true`。统计总数不截断。
- 沿用插件 30 秒超时、2 MB 输出限制及取消清理。较大彩色点云仍可能触及字节上限；后续数据句柄接口继续开发。
- 模型可绑定全局、流程、模块变量。拟合失败时模型字段不存在，后续模型使用前应通过条件节点检查 `found`。配置错误和坐标系不一致会使流程失败并回滚本轮变量。

## 演示与验证

“演示案例 → 3D”提供五种合成演示：倾斜圆柱与离群点、凸起/凹陷、拟合→变量→侧面偏差、12° 周向覆盖不足、22 mm 直径超差。生成脚本为 `scripts/generate-cylinder-samples.py`。

`tests/test_cylinder.py` 覆盖任意轴向、两种拟合模式、噪声/重复点/离群点、部分周向覆盖、短轴向跨度、退化点集、偏差符号和颜色索引、米单位/大平移、抽样后的全点验证、模型错误及资源限制。`tests/test_cylinder.cjs` 与 HTTP 集成覆盖真实 Python 子进程、三级模型变量、失败回滚、坐标保持和真实 Node-RED 拟合→检测链路。

开源来源：[SciPy GitHub](https://github.com/scipy/scipy)、[least_squares 官方文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.least_squares.html)。圆柱五自由度参数化、质量控制与平台适配为本项目实现。另调研了 [PCL 圆柱分割教程](https://pointclouds.org/documentation/tutorials/cylinder_segmentation.html)，其法向辅助采样一致性流程没有作为本插件实现或依赖引入。
