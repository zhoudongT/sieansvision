# SIEANS 圆孔与双圆测量

`sieans-circle` 1.0.0，接口版本 1，MIT。依赖已锁定的 OpenCV 与 NumPy，无需新增包。参数用插件表单，模型用字段表与变量绑定，卡尺明细和结果用表格。开发源码 0.3.0-dev 提供此插件；已发布的 0.2.0 ZIP 未修改。

## 圆形卡尺

在预计圆心和半径周围布置径向卡尺，沿半径**向外**采样；切向多像素平均、Gaussian 平滑、灰度梯度峰值及抛物线插值提取边缘。亮到暗适用于亮圆外边缘，暗到亮适用于暗孔外边缘或亮圆环内边缘。多个候选点可选最强、最内或最外边缘。

拟合用确定性 RANSAC 选择支持圆，再以径向距离的几何最小二乘迭代，超阈值点单调剔除。至少六个采用点，拒绝重复/近共线、病态或不收敛求解；拟合半径必须落在用户搜索环带。有效角度覆盖按拟合圆心计算：360° 减去相邻采用点之间的最大角度缺口。完整圆搜索不重复首尾卡尺，局部圆弧包含两端。

表单配置中心、预计半径、径向长度、切向宽度、数量、顺时针起始角/圆弧范围、极性/选边、梯度/平滑、残差剔除、RMS、有效比例、角度覆盖、长度比例和直径公差。图像坐标原点左上，X 向右，Y 向下，角度顺时针。

`found` 表示形成稳定且覆盖充分的圆；`passed` 还要求采用点数 / **全部卡尺数** 达标、RMS 合格、直径在范围内。无边缘或拟合失败返回诊断、原卡尺明细、`found=false`、`passed=false`，省略圆模型/直径等测量值。不能把未找到时缺少的模型绑定为有效模型；必需字段绑定会使该轮失败并回滚变量。

每行记录序号、采样角度、检出/采用状态、边缘像素坐标、梯度、径向残差和原因。偏移点仍保留；RMS、最大偏差及径向残差范围仅描述**拟合采用点**，不能用它们替代全轮廓缺陷检查或标准圆度计量。有效比例决定最多接受多少未检出/剔除点；剔除过于宽松会掩盖真实缺陷。

圆心/半径像素值和图像尺寸存入 `sieans-circle-v1` 模型，同时存长度单位、均匀比例和原始图像内容摘要。直径 = 2 × 半径 × 比例；像素单位要求比例为 1。毫米等单位比例必须来自用户标定，只适用于已校正且比例近似均匀的同一测量平面。透视、畸变、非均匀缩放和分辨率变化会影响测量，需要先处理。

## 双圆中心偏移与理想壁厚

两个圆模型通过表单字段或变量引用绑定；必须具有相同原图摘要、图像尺寸、单位和比例。若当前流程还有图像，继续验证模型与当前图像一致。验证防止混用两帧数据；不证明相机时间同步、实物身份或物理标定准确度。

外圆半径必须大于内圆。中心距离 `d` 为两圆心距离；当 `d < R外 − R内` 时内圆完全位于外圆中，理想圆最小/最大壁厚为 `(R外 − R内 ∓ d) × 比例`。检测同时比较中心距离上限、最小壁厚下限和最大壁厚上限。内圆未完全包含时返回 `nested=false`、`passed=false` 并省略壁厚值。中心重合是有效情况，距离为 0，最小/最大壁厚均为半径差。

此处测量的是两个**拟合的理想圆**，不是沿真实轮廓的局部壁厚，不是 GD&T 同心度/同轴度。输入来自单张 2D 图像，也不能给出轴线在 3D 空间中的偏移。需要将圆卡尺的检测通过状态作为条件时，可在双圆前用流程判断节点控制。

原图继续传给下游，标记图仅用于显示。圆卡尺绘制搜索线、采用/排除点、拟合圆和圆心；双圆绘制两圆及中心连线。标记 JPEG 上限约 700 KB，过大时明确报错。最多 360 个卡尺、200 万个采样点，执行超时 10 秒；取消/超时沿用独立 Python 进程回收机制。

## 演示与验证

演示案例的“测量”分类增加七例：小数圆心与 16.08 mm 直径、直径超差、局部 6 px 偏移剔除、部分遮挡、无边缘、正常圆环和偏心圆环。正常圆孔和两种圆环带数值/状态灯/标记图/明细表运行画面。所有图片均为可重复生成的合成光栅，0.1 mm/px 是演示比例，不代表真实相机标定。

```powershell
npm run test:circle
```

数值测试覆盖多种极性、内外选边、噪声、遮挡、公差、局部圆弧、退化输入、均匀比例及双圆壁厚；实际 Python 流程验证三级变量、回滚、原图传递、HMI 绑定、Node-RED 与异帧拒绝。HTTP 验证插件表单元数据、结果/历史、工程保存与重启。界面可视验收、真实镜头/工件精度与 Linux 实机验证仍待完成。

图像解码、滤波、插值采样和绘制使用 [OpenCV GitHub](https://github.com/opencv/opencv)，采样映射参照其[官方 remap 说明](https://github.com/opencv/opencv/blob/5.x/doc/tutorials/imgproc/imgtrans/remap/remap.markdown)。矩阵计算使用项目既有 NumPy。径向卡尺布置、RANSAC/几何拟合、模型约束、单位与双圆检查为本项目实现，未复制商业软件算法源码。
