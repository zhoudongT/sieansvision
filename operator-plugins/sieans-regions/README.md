# SIEANS 色彩与斑点检测 1.0.0

使用项目锁定的 OpenCV / NumPy，无额外模型。插件在工具箱自动显示“HSV 色彩区域检测”和“灰度斑点分析”。输入、参数及结果遵循平台 API v1，代码许可见 LICENSE。

- HSV 使用 OpenCV 8 位定义：H=0–179、S/V=0–255。H 下限大于上限表示跨越 179→0；S/V 不允许倒置。
- 灰度亮目标为 `灰度 > 阈值`，暗目标为 `灰度 <= 阈值`。可选择 4/8 邻域、开/闭运算、面积筛选和排除区域边界目标。
- 矩形区域在插件表单设置 X/Y/宽/高；宽高为 0 时延伸至输入图像边界。区域外不参与分析。工作台通用 ROI 框不替代这些插件区域参数。
- 面积是前景像素数，孔洞不计入；质心和包围框坐标均相对于完整输入图像。数量判定只统计通过面积和边界筛选的区域。
- 原图、筛选后的二值区域或编号标注图可传给下游。默认原图；需要后续斑点分析时显式选择二值区域，避免标注线参与检测。
- 明细最多 500 条，按面积降序及位置排序；总数、总面积、判定使用全部合格区域。标注图仅标记明细中的目标。
- 输出包含目标数量、面积、覆盖率、最大面积、目标明细和通过/未通过，可绑定三级变量。

依赖及来源：[OpenCV 仓库](https://github.com/opencv/opencv)、[HSV 范围阈值](https://docs.opencv.org/4.x/da/d97/tutorial_threshold_inRange.html)、[连通区域统计 API](https://docs.opencv.org/4.x/d3/dc0/group__imgproc__shape.html)。此插件是针对平台编写的封装，不是复制第三方插件。

演示：“色彩区域 · 红色跨端点筛选”和“色彩掩膜 → 斑点尺寸筛选”。合成图中两块红色像素面积分别为 12000、4800；后者按最小面积 6000 筛选剩一块。生产使用需在现场光照和相机色彩条件下调整阈值。
