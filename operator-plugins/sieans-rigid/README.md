# 3D 对应点标定与坐标转换

`sieans-rigid` 1.0.0，MIT，使用已安装的 NumPy，不增加依赖。参考 [Open3D GitHub 对应点变换接口](https://github.com/isl-org/Open3D/blob/main/cpp/open3d/pipelines/registration/TransformationEstimation.cpp) 及 [SciPy Kabsch 算法说明](https://docs.scipy.org/doc/scipy/reference/generated/scipy.spatial.transform.Rotation.align_vectors.html)，采用中心化点集/SVD 实现刚体拟合；本插件不调用 ICP 搜索对应关系。

## 工作台流程

1. 选择“3D 对应点刚体标定”。填写输入坐标系（例如 camera-optical）、目标坐标系（例如 fixture-base），分别选择两组点的长度单位 mm 或 m。
2. 在六列对应点表中，按行填写同一物理点的输入 X/Y/Z 和目标 X/Y/Z。至少三个不共线的不同点，建议六个以上、覆盖检测空间的点。**默认点表是合成演示样例，生产使用必须替换。** 点表最多 500 行，可整体绑定变量或上游结果。
3. 选全部点拟合或 RANSAC。距离阈值、最大 RMS 和最大单点误差均采用目标点单位；从 mm 改 m 后，阈值也应按实际含义调整，软件不自动改写阈值。全部点拟合不使用 RANSAC 抽样参数。
4. 输出表显示内点/排除点数、每点残差及拟合内点误差。将完整 `calibration` 输出绑定流程或全局变量，如 `frameCalibration`。模型同时包含方向、单位、旋转和平移，请不要只复制矩阵。
5. 添加“3D 点位坐标转换”，将标定输入绑定上述变量，填写新点表。结果按行展示输入/输出三维坐标；可将 `items.0.targetX` 等字段绑定三级变量，再连接工业通信算子。普通转换不自动写设备。
6. 或添加“3D 点云坐标转换”：输入点云的 frame/unit 必须与选定方向匹配，输出点云更新 frame/unit，再进行工装坐标下的区域、位置或尺寸检测。
7. 添加“3D 标定独立点验证”，用没有参与拟合的点表检验目标对应坐标。超限返回 `passed=false`，供条件分支或报警使用，不重新拟合或替换原模型。生产通信/动作分支需自行配置，仅在验收通过后执行。

所有设置均为表单、坐标表及变量绑定，后台模型仍按结构化数据保存。工作台和集成 Node-RED 通用“扩展算子”共享同一插件及固定版本契约。

## 方向、单位与数据通道

正向定义为：`目标点 = R × (输入点 × 单位换算系数) + t`。平移 t 以目标单位计；仅估计旋转和平移，不估计未知比例、剪切或反射。毫米与米是明确声明的单位换算，不是比例拟合。反向开关会使用逆变换并交换输入/输出坐标系和单位，不能仅翻转名称。

旋转必须为 3×3 正交矩阵且行列式为 +1，平移为有限三维数值。重复位置、共线/过窄分布、无效模型、内点不足、拟合误差超限会拒绝标定；失败时不生成新模型，运行事务中的变量修改不提交。之前已提交的标定变量仍可能存在，应以本轮状态为准。

点云转换最多 20 万点。颜色和采集时间保留；存在法向时只旋转法向。旧相机内参/外参、像素映射及其他未声明的自定义点云元数据不保留，同时清除关联的图像和原始深度通道，避免混用坐标。点位表转换和标定本身不改变输入数据通道。

模型只适用于两坐标系之间保持固定刚性关系的情况。它不是通过多组机器人运动求解的手眼标定，也不校准镜头、机器人关节或工具中心。三个点或全部共面点可以确定理想刚体对应关系，但不能充分检验空间范围内的误差；建议使用不共面的独立验证点。低训练残差不等于现场精度，RANSAC 排除的点也不能据此认定测量设备故障。现场轴定义、右手坐标约定、单位及有效范围均需独立确认。

## 演示与验证

演示菜单增加五项：

- 八点标定与新点转换：绕 Z 轴旋转 90°，平移 (300,500,100) mm；(10,20,30) 转为 (280,510,130)。
- 一个错误配对的 RANSAC 排除：七个内点、一个排除点，恢复相同关系。
- 点云转换后真实 Open3D 尺寸测量：工装坐标范围 X=200–300、Y=500–600、Z=100–200 mm。
- 三个独立验证点，其中一个偏差 2 mm，返回不通过。
- 转换后 X=280 mm 写入本机 Modbus 模拟器的保持寄存器 80–81（float32）并读回，不访问现场 PLC。

`npm run test:rigid` 包含七项 Python 数值/错误数据测试、三项真实 Python 子进程运行时/三级变量/回滚/Node-RED/模拟 Modbus 测试，以及 HTTP 插件发现、六列点表元数据、工程与模型保存、坐标系拒绝和重启后再次执行。57 项相关插件/运行时/流程图/球面/圆柱/内参回归及语法检查通过。所有案例是合成点位，尚无实际工件/机器人、真实 PLC、Linux 和新增界面可视验收，不代表已经完成生产坐标标定。
