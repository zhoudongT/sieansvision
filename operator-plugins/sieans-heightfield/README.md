# 倾斜基准高度与可见体积

`sieans-heightfield` 1.0.0 / API 1 / MIT，适用于 0.3.0 开发源码，使用项目既有 NumPy，无新增依赖。独立基准点表和参数使用表格/表单，平面模型通过变量绑定；结果与缺测网格以表格展示。0.2.0 已发布包未修改。

## 独立高度基准

“3D 高度基准 · 独立平面标定”读取 **3–1000 行独立基准点**，不是用待测工件表面自动拟合基准。用户声明单位 mm/m、坐标系、正法向提示和 U 轴方向提示；点与测量云必须处于同一坐标系和单位。空坐标系名称表示未命名的局部坐标系，仍要求两端一致。

去除完全重复坐标后做 SVD 最小二乘平面拟合，以独立点计算 RMS/最大残差。共线/近共线/重合点、零方向提示、无法确定正方向或 U 方向时报错；误差门限不满足时正常返回 `found=false, passed=false`，省略模型。三个点总能定义平面，并不证明现场基准精度，建议使用分布良好的更多独立测点。

模型 `sieans-plane-grid-v1` 保存独立点质心作为原点、投影到平面的 U 轴、右手 V 轴和单位法向，以及单位/坐标系。正法向跟随提示方向；反转提示会反转高度正负，并使 V 轴反向。U 轴提示与法向接近平行时拒绝任意选轴。拟合没有 RANSAC，不会暗中剔除错误测点；需要先排查基准点来源。

模型可写入流程/模块/全局变量，再绑定给积分节点；也可在表单中使用已有模型。后续读取时验证右手正交单位基。相机或物体坐标发生变化时需要相应变换模型/点云或重新标定，不能套用旧基准。

## 高度网格与观测体积

点先投影到基准的 U、V、法向坐标。定义 U/V 最小值、公共格边长及两个方向的格数，形成固定矩形 ROI；每格为半开区间，下边界包含、上边界排除。整体 ROI 右/上边界上的点不纳入统计，结果报告 ROI 内/外的独立点数。网格方向/原点固定后可以跨测量重复比较。

完全重复 XYZ 坐标去重，防止复制同一点增加采样数。每格可取向正法向的最高点或独立点平均高度。至少达到设定独立点数，且同格最高/最低高度跨度不超过门限，才作为有效格；跨度过大可提示层叠表面、侧壁、粗采样或异常点。最高点统计有上偏风险，均值受点密度和多层影响，门限和格大小需要按实物/密度验证。

| 输出 | 含义 |
|---|---|
| coverage | 有效格数 / 全部定义格数；不以已采样格数为分母 |
| observedArea | 有效格数 × 格边长² |
| positiveVolume | 所有有效格的 `max(代表高度,0) × 格面积` 之和 |
| negativeVolume | 所有有效格的 `max(−代表高度,0) × 格面积` 之和，返回正的绝对值 |
| netVolume | 正向观测体积 − 负向观测体积 |
| minimum/maximumHeight | 有效格代表高度的范围，不是全部原始点的极值 |

这些值是相对于所选平面的**可见单值高度表面网格估计**，不是封闭实体真实体积，不补齐遮挡、内部空洞、倒扣、背面或未知侧壁。格中只有一个点也不能证明整格表面已被充分观测；应按采样间距设最小点数并检查覆盖。没有有效格时返回 `found=false` 并省略高度/体积；有缺失或无效格时可报告已观测部分的估计，但不能声称完整体积。

`passed` 同时要求存在有效格、覆盖率达到门限、所有有效格高度在公差内、正向观测体积在指定范围内。负向体积和净体积不直接参与此公差；需要时可接条件判断节点自行比较。数值边界只加入浮点舍入量级容差，不能代替测量误差预算。大坐标配极小格边长若低于可靠数值精度会拒绝，需先转局部坐标。

长度、面积和体积分别跟随点云单位、平方单位和立方单位。模型与点云 mm/m 不一致会报错，不自动猜测换算。若从 mm 改为 m，模型原点、点云坐标、格边长、U/V 起点及所有长度门限均须缩小 1000 倍，体积门限须缩小 10⁹ 倍；可用既有刚体变换插件处理坐标/单位，再建立对应基准。

## 明细、颜色与运行画面

每行给出格行/列（从 0 开始）、U/V 中心、独立点数、有效/通过状态及原因；已采样格显示高度跨度，有效格才有高度和有符号体积。缺测格不会显示伪造的零高度。可选全部格或缺测/无效/高度超差格，最多显示 1000 行，摘要始终统计全部格并报告明细截断。

点云坐标、顺序、单位、坐标系及采集元数据保留，只改颜色：绿色是有效且高度合格格，红色是高度超差格，橙色是采样不足/跨度超限格，ROI 外点灰色。体积或覆盖率整体不通过时，局部合格点仍可为绿色，应以总体判定为准。没有采样的格不存在可着色点，须看明细表。

网格最多 65536 格，单方向最多 512；输入最多 200000 点。着色输出最多 10000 点，较大点云需先下采样或关闭着色；关闭后仍保留原云供下游使用。算子执行上限 10 秒，错误/超时沿用运行时变量回滚，插件输出仍受通用字节上限约束。

“演示案例 → 3D”新增五例：30° 倾斜基准测得 2 mm/32 mm³；缺十格只报告 24 mm³ 且覆盖 90% 不通过；凸起 32 mm³ 与凹槽 10 mm³ 分开报告；同格多层诊断；已有基准直接测量。各例带观测体积、法向高度、覆盖率、状态灯及网格表运行画面。全部为合成数据，不代表真实相机精度。

运行 `npm run test:heightfield` 验证数值、毫米/米及立方换算、法向正负、缺测、重复点、多层、范围、着色、变量绑定/回滚、Node-RED、HTTP 工程/历史/画面保存与重启。新增界面可视验收、真实体积相机/工件、现场节拍与 Linux 实机仍待完成。

## 公开来源

矩阵、去重和分组统计使用 [NumPy GitHub](https://github.com/numpy/numpy)，分组数量/加权和采用 [`numpy.bincount`](https://numpy.org/doc/stable/reference/generated/numpy.bincount.html)。基准模型、网格有效性、统计、公差和平台集成为本项目实现。本插件没有调用凸包或水密重建来冒充可见表面测量；复杂实体体积重建仍需另做。
