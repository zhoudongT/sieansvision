# SIEANS 2D 边缘卡尺 1.0.0

使用项目现有 OpenCV / NumPy，不新增第三方 Python 依赖。插件自身采用 MIT；依赖库沿用各自许可证。算法实现为本项目代码，OpenCV 提供采样、滤波、拟合和绘图。

## 两个流程算子

- **边缘卡尺 · 直线拟合**：多条平行灰度扫描，宽度方向平均，高斯平滑，梯度局部极值与抛物线插值；按极性和第一/最后/最强选择边缘。先 Huber 稳健拟合，再剔除超出残差的点并最小二乘拟合，至少 3 个有效点。
- **双边缘卡尺 · 测宽**：选相邻、极性相反且距离在搜索范围内的一对边缘。亮条带为暗→亮→暗，暗条带相反；多对候选按两边中较弱梯度最大的那一对选取，分数相同取扫描方向最前一对。逐卡尺计算宽度、公差和总体统计。

中心采用图像像素中心坐标，X 向右、Y 向下；角度从向右方向顺时针增加。各卡尺中心沿扫描方向的垂线排列。搜索长度是沿扫描方向的跨度，间距是相邻卡尺中心距离，平均宽度是垂直扫描方向的采样点数（点距 1 px）。可在参数表将数值绑定至流程/模块/全局变量或上游结果。

图中蓝框/箭头为搜索区域/方向，黄色点为宽度边缘，绿线为合格测宽，红线为超差；直线拟合黄线、绿点为采用点、红点为剔除点。越界搜索框标红并跳过，不用补零生成假边缘。

## 判定与单位

- 直线：有效比例为拟合采用点数/全部卡尺数；比例达标且拟合 RMS 不超过限制才通过。
- 宽度：有效比例为检出边缘对数/全部卡尺数；比例达标且所有检出的宽度都在公差内才通过。未检出行仍在表中，若要求每组都成功，将最低有效比例设为 1。
- 搜索最小/最大间距用 **px**；合格宽度上下限用所选输出单位，两者独立。`px` 单位要求比例为 1；mm/cm/m 使用每像素实际尺寸进行均匀换算。
- 输出宽度是**沿扫描方向的截距**。应使扫描方向垂直条带，倾斜扫描不会自动校正为法向宽度。均匀比例只适用于对应成像配置和平面，不补偿透视/镜头畸变。
- `found` 表示形成了拟合/测宽结果，不等于通过；`passed` 才是公差判定。无结果时不返回直线、RMS 或宽度统计，不填假零值。配置错误使流程失败；未检出或超差是正常检测结果，`passed=false`。
- 亚像素插值是数值位置估计，不代表可达某个实际精度。现场需使用可溯源尺寸、镜头与光照条件验证。

## 图像通道

本插件只返回 `annotatedImage` 作为标记图，不返回 `image`，因此下游算法、ROI 输入预览和 Node-RED `msg.image` 保留原始图像。Node-RED 第二输出用于显示标记图。现有处理型插件仍可返回 `image` 改变下游图像。

## 资源与验证

最多 100 个卡尺，长度 2048 px，平均宽度 51 点；组合采样量不超过 200 万。高斯支持域和边界梯度被排除，较大平滑尺度需更长搜索区域。响应仍受插件接口 2 MB 限制，大图应先裁剪或缩小。

`scripts/generate-caliper-samples.py` 生成四个可重现演示：离群点直线、倾斜条带合格、宽度超差、无边缘。`tests/test_caliper.py` 覆盖已知 321.35 px 边缘、80.4 px 宽度、多角度/反向/明暗、噪声、离群点、越界与错误参数；在这些合成测试中使用 0.15 px 容差，不是产品精度指标。Node 测试及 HTTP/Node-RED 集成验证真实子进程、变量和图像通道。
