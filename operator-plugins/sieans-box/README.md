# 3D 旋转包围盒尺寸

`sieans-box` 1.0.0，MIT。使用现有 Open3D/NumPy，不增加依赖。基于 [Open3D 官方仓库](https://github.com/isl-org/Open3D) 和 [旋转包围盒接口](https://www.open3d.org/docs/latest/python_api/open3d.geometry.OrientedBoundingBox.html) 的凸包方向优化，区别于原有沿输入 X/Y/Z 坐标轴的包围尺寸。

## 使用

1. 输入完整目标点云；多目标、背景和离群点先通过裁剪、去平面、聚类或滤波处理。算子不会自行剔除点来缩小尺寸。
2. 添加“3D 旋转包围盒尺寸”，设置最小可靠厚度和长/中/短边公差。**所有距离和公差沿用输入单位 mm 或 m**，不自动换算。
3. 运行后在结果表查看长中短边、公差、包围盒中心、八个角点、右手单位轴和原 X/Y/Z 包围尺寸对照。公差表每行带单位，便于直接绑定 HMI 表格。可将尺寸、判定或角点表绑定三级变量。

算法先对独立点去重和中心/尺度归一化，拒绝秩不足及病态薄点集；生成三维凸包，再使用 Open3D `get_minimal_oriented_bounding_box(robust=False)` 优化方向。对返回方向的小量浮点非正交误差执行正交化，然后对**全部接受的原始点**重新投影求极值，生成真正包围这些点的尺寸和角点。按长/中/短排序并统一为右手轴。不会使用随机扰动给平面补造厚度。

该方法搜索凸包候选方向，**不保证任意形状的数学全局最小体积**；结果不称为精准工件姿态。长方体合成数据用于已知尺寸验证，其他形状不能据此承诺同样的物理含义。

## 范围与限制

- 输出是**已输入点集的包围尺寸**。遮挡、缺面或采样不足会改变尺寸；离群点会扩大包围盒。未验证目标点云完整性，不能把任意可见表面的包围尺寸直接当作实物长宽高。
- `boundingBoxVolume` 是旋转包围盒体积，`axisAlignedVolume` 是坐标轴包围盒体积，**均不是实体体积**。体积数值采用输入单位的三次方。空洞、倒扣、内部结构、材质和质量均未推断。
- 单位轴与中心是包围盒几何描述，不是具有唯一解的定位、机器人抓取或安全运动指令。等长/近等长边会提示方向可能不稳定；即使尺寸不同，也不证明只有一个有效方向。符号约定和排序不能消除工件对称性。
- 共面、共线、独立点不足或厚度病态时明确失败；本轮变量回滚。不返回伪造的零厚度三维盒。平面应使用平面/二维尺寸算法。
- 公差按浮点测量结果直接比较；现场公差必须结合点云误差、分辨率、采样和数值精度设置，不能依靠显示小数位声称计量精度。
- 输入 4–20000 点，去重后至少四点，凸包最多 2048 个三角面。超限明确失败，需由流程显式裁剪/滤波/下采样；不隐式丢弃点或只测量抽样子集。仍受平台进程超时和数据预算限制。
- 原始点云、颜色、深度及图像通道保持不变。HMI 显示原始点云和尺寸公差表；当前没有旋转盒线框叠加，角点可在表格查看。主点云视图原有坐标轴包围框仍是原 X/Y/Z 尺寸，勿混同。

## 演示与验收

`scripts/generate-box-samples.py` 生成完整长方体表面及三轴旋转，四个演示涵盖 20×10×5 mm、长边超差、米单位、等边方向提示。每个带数值/判定灯、原始点云和公差表 HMI。`npm run test:box` 包含已知尺寸、全点包围约束、右手正交轴、角点、去重/大平移、离群点影响、退化/复杂度拒绝、真实插件/三级变量/回滚、Node-RED、HTTP 保存/历史和重启验证。

这是合成软件验证，尚无实物完整性、精度、节拍、Linux 或新界面真实窗口验收。工作目录和开发预览包含该插件；冻结的 0.3.0-dev-candidate-2 ZIP 未重新打包。
