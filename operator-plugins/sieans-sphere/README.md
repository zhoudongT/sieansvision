# SIEANS 三维球面检测 1.0.0

独立 Python 插件提供球面拟合和基准球面径向偏差检测。参数使用功能表单，基准模型使用字段表或变量绑定，结果使用明细表和点云着色。插件代码采用 MIT，新增依赖 SciPy 1.18.1 使用 BSD-3-Clause，发行包许可证及打包依赖说明见 `third_party/scipy/LICENSE.txt`。

安装到现有环境：

```powershell
.venv/Scripts/python.exe -m pip install -r vision/requirements-3d.txt
```

Linux 对应使用 `.venv/bin/python`。本轮已验证 Windows / Python 3.12 / NumPy 2.5.4 / SciPy 1.18.1；Linux 和实物点云准确度仍需验收。

## 3D 球面拟合

1. 点云坐标必须是 mm 或 m，阈值、半径、直径公差使用同一单位。至少需要 8 个独立坐标点，重复点不重复参与拟合或内点比例统计。
2. 对独立点以固定随机种子均匀抽样，默认最多 5000 点、可设 8–10000 点；输出 `sampleCount` 告知实际样本数。缩放、平移归一化后进行数值求解。
3. RANSAC 用四点候选球面，按内点数最多、内点均方残差最小排序；也评估全样本代数初始解。用户控制尝试次数和搜索半径。选择“采样点最小二乘”时不做随机候选剔除。
4. SciPy `least_squares` 使用解析雅可比和有界半径，最小化 `||点-球心||-半径` 的几何残差。RANSAC 最多进行 8 轮内点重新分类；不收敛或内点集合不稳定则不给出有效球面。
5. 用最终拟合雅可比的条件数检查可辨识性。共面/共线、过窄球冠、有效点不足等会返回 `found=false`、`passed=false` 和诊断，不输出球心、直径或模型。条件数阈值是数值稳定性控制，不是现场测量精度证书。
6. 对**全部原始点和全部独立点**计算残差。`inlierRatio` 为独立内点数 / 独立总点数，RMS 也按独立内点计算；表格、超差点计数与着色则保留原始点索引和重复点。
7. 内点比例、内点 RMS、直径公差全部达标才 `passed=true`。形成了可用模型但尺寸超差时，`found=true`、`passed=false`，模型仍可供诊断或下游使用。未形成模型时，下游需要先用条件节点检查 `found`，不能直接绑定不存在的模型字段。

绿色点表示拟合内点，红色表示超过拟合内点阈值；它们不表示直径公差是否合格。无法拟合时点云为灰色。抽样和 RANSAC 不保证找到场景中每一个球，应先分割目标点云。

## 3D 球面偏差检测

基准 `sphere` 可直接填写字段表，也可绑定上一步拟合结果或三级变量。模型格式为 `sieans-sphere-v1`，包含球心 `center`（X/Y/Z）、正半径 `radius`、单位和坐标系 `frame`。输入与基准的单位、坐标系必须完全一致；不会自动缩放、配准或转换坐标系。

径向偏差为 `点到球心距离 - 基准半径`，正值在球外，负值在球内。下限/上限和允许超差点比例控制判定；RMS、最小/最大偏差及峰谷差按全部输入点统计。基准拟合再检测同一件工件适合观察局部形状偏差，但会吸收整体位置/尺寸变化；绝对位置、尺寸验收应使用独立固定基准和单独的直径判定。

这些指标仅针对已观测的点，不等同于完整球面覆盖、标准最小区域球度或实体体积测量。点在基准球心处的径向偏差为负半径，仍会纳入检测。

## 输出与资源边界

- 保留原始坐标、点序和坐标系，只替换颜色；颜色输出上限 10000 点。较大点云可关闭着色，对全部点进行偏差验证，或先下采样。
- 每次显示最多 500 个点位明细，可选择全部点或仅超差点；统计总数不截断，超过时 `detailsTruncated=true`。
- 插件接口仍有 2 MB 响应限制和 30 秒超时；较大点云需要后续的数据句柄接口。超时、配置错误、基准单位/坐标系不匹配属于流程错误，检测不通过属于正常结果。
- 输出模型可以绑定模块、流程、全局变量，Node-RED 通用扩展算子也可将 `payload.sphere` 绑定给下一节点。

## 演示与验证

`scripts/generate-sphere-samples.py` 生成五个演示：20 mm 球面与 40 个离群点、+0.5/-0.3 mm 局部偏差、拟合到变量再检测、5° 球冠覆盖不足、22 mm 直径超差。所有数据均为合成场景，不代表真实相机效果。

`tests/test_sphere.py` 验证已知球心/半径、噪声、离群点、重复点、球冠条件数、退化点集、径向符号、单位与大平移、采样后全点验证、资源上限。`tests/test_sphere.cjs` 和 HTTP 集成覆盖真实子进程、模型变量、回滚、坐标保持及实际 Node-RED 拟合→检测链路。
