# 2D 轮廓建模与形状识别

`sieans-shape` 1.0.0，MIT。使用已安装的 OpenCV/NumPy，不增加模型权重或依赖。实现依据为 [OpenCV 官方 GitHub 仓库](https://github.com/opencv/opencv)、[轮廓与 Hu 形状匹配 API](https://docs.opencv.org/4.x/d3/dc0/group__imgproc__shape.html) 和 [轮廓匹配教程](https://docs.opencv.org/4.x/d5/d45/tutorial_py_contours_more_functions.html)。这是平台封装，不是复制第三方商业软件的识别实现。

## 工作流程

1. 加入“轮廓形状 · 建立模型”，选择前景极性、灰度阈值、参考区域和外轮廓面积范围。区域内必须恰好存在一个符合面积范围且完整的目标；接触区域或图像边界的目标排除。区域宽高 0 表示延伸到图像边界。
2. 在输出绑定表将“轮廓模型”写入流程变量或全局变量。建模失败则本轮变量回滚，旧模型不会自动删除；应先检查本轮状态。
3. 加入“轮廓形状 · 旋转缩放识别”，将模型绑定到上述变量或上游 `model` 结果，设置搜索区域、Hu 差异上限、面积等效比例、孔洞检查和合格数量。
4. 结果明细表包含完整候选的外轮廓质心、外轮廓面积、旋转包围框长短边、孔洞数量、Hu 差异、面积等效比例及接受/拒绝原因。通过表示匹配数量落在配置范围，找到表示至少一项匹配，两者独立。空搜索区域返回 0 且不通过，不产生伪造的坐标。

模型可保存到全局变量供另一个工程或后续图像使用；生产检测流程只放识别算子，从保存的模型变量读取，不必每帧重新建模。不要把检测中的目标无条件重新作为良品模型。示例为了可单次运行，在同一张合成图左侧放参考、右侧放待测目标。

工作台通过自动参数表单和变量绑定操作，HMI 提供数值、灯、图像与候选表。原图继续传递下游，标记图独立输出，不让编号/边界线参与后续检测。

## 算法与判定范围

- 二值分割采用亮目标 `灰度 > 阈值` 或暗目标 `灰度 ≤ 阈值`；使用 `RETR_CCOMP` 和 `CHAIN_APPROX_SIMPLE` 提取轮廓，Hu `CONTOURS_MATCH_I1` 只比较外轮廓。支持完整、可分割轮廓的平移、旋转和均匀缩放比较；栅格化和分割误差会改变差异值。
- Hu 差异越低越相似，不是置信度、概率或百分比。不同形状可能具有相近矩值；镜像也可能混淆。**不用于正反面判定，不输出旋转角、抓取姿态或定位跟随变换**。遮挡、接触粘连、透视变形、低对比/复杂背景需另行分割或采用其他算法。
- 比例为 `sqrt(候选外轮廓面积 / 模型外轮廓面积)`，是面积等效线性比例，不是已求得的几何变换。面积和长短边单位都是像素，不是标定后的实际尺寸。
- 质心来自外轮廓几何矩，不扣孔洞，不是净材料质心、参考图绘制锚点或质量重心。旋转包围框边长不提供方向信息。
- 孔洞检查默认开启。将孔洞轮廓面积除以外轮廓面积，排除小于最小比例的孔洞，再比较数量及按面积降序排列后的比例绝对差。**不比较孔洞形状、位置或排列**，故不能证明孔位正确。外轮廓面积不扣孔洞，也不同于前景像素数量。
- 两层轮廓中的孔洞内独立前景岛视为另一候选。边界截断目标会被排除并报告数量；数量范围只针对面积筛选后完整候选中的匹配项，不保证区域边界外没有其他目标。缩小搜索区域或修改阈值会改变候选集合。
- 不做平滑、形态学或自动阈值。需要时可由前置预处理提供图像；参考与检测使用相同的预处理约定，现场须调整分割和判定门限。

## 有界执行与验证

图像最多 1600 万像素，单边最多 32768；最多 10000 条分割轮廓、200 个完整面积候选；每条轮廓最多 4096 点，每目标含孔洞最多 12000 点/64 孔洞，候选总点数最多 100000。超过上限明确失败，不用截断的结果宣称计数完整。模型加载重新计算面积/矩和孔洞比例，拒绝退化坐标、非法类型、外部孔洞及超限记录。仍受平台独立进程、超时、结果大小和变量事务限制。

`scripts/generate-shape-samples.py` 可复现五个演示：三个角度/比例目标与圆形干扰、缺孔、无目标、唯一目标失败、暗前景。每个提供 HMI 数值/灯/标记图/候选表。`npm run test:shape` 执行已知合成数值、真实插件进程、三级变量、回滚、Node-RED 桥接，以及 HTTP 参数元数据、工程/模型/历史保存与重启复用验收。

合成软件验证不能证明现场识别率、计量精度、节拍、真实工件或 Linux/新界面视觉验收。已冻结的 0.3.0-dev-candidate-2 ZIP 不包含本次新增插件，当前工作目录包含。
