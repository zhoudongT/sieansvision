# SIEANS 三维表面检测 1.0.0

“3D 平面偏差检测”使用 NumPy 计算点到平面的有符号垂直距离，输入为平台点云，坐标与距离沿用输入的 mm 或 m 单位。代码许可见 LICENSE。

## 两种基准

- 指定基准：表单填写 a/b/c/d，平面为 aX+bY+cZ+d=0。距离按法向量长度归一化；正负由输入法向决定。例如 z=10 对应 a=0、b=0、c=1、d=-10。
- 最小二乘拟合：使用全部点的中心化 SVD 拟合平面。至少 3 个不共线点；共线或重合输入拒绝。为保持符号稳定，法向量中绝对值最大的分量取正。该模式不使用手填的 a/b/c/d。

设置有符号距离下限/上限和允许超差点百分比。落在含边界公差带内的点合格，超差比例小于等于允许比例时通过。仅对浮点舍入误差施加机器精度量级的补偿。

结果包括点数、超差点数/比例、最大/最小有符号偏差、峰谷差、均方根、归一化平面方程及前 500 个超差点。点索引从 0 开始，统计不受明细截断影响。可输出红色超差、绿色合格点云，保留全部点、单位及坐标系；着色模式最多 10000 点，超过时明确报错。关闭着色可分析平台允许的完整输入点云并保留原始通道，不偷偷下采样。

这是相对于基准或最小二乘平面的采样偏差检查，**不是最小区域平面度、完整表面轮廓度或计量认证结果**。拟合模式不自动剔除离群点，异常点会影响基准；可先使用现有 Open3D 裁剪/离群点滤波，或直接使用标定后的固定基准。部件朝向、测量坐标系、设备标定和误差验收由项目确定。

与既有 [Open3D](https://github.com/isl-org/Open3D) 点云管线使用相同数据通道，本算子数值计算仅依赖已有 NumPy。演示“3D 表面 · 凸起与凹陷偏差”使用 121 个合成点，z=10 mm 基准及 ±0.1 mm 公差，2 点超差（+0.5、-0.3 mm）。
