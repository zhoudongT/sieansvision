# 平面透视标定与测量

独立 Python 算子包 `sieans-planar` 1.0.0，MIT。依赖现有 OpenCV/NumPy 环境。通过 OpenCV `findHomography` 建立平面单应性，见 [官方仓库教程](https://github.com/opencv/opencv/blob/5.x/doc/tutorials/features/homography/homography.markdown) 和 [API 文档](https://docs.opencv.org/4.12.0/d9/d0c/group__calib3d.html)。

## 操作流程

1. 添加“平面透视标定”，在标定点表中按行填写图像 X/Y 和对应的实际 X/Y。至少四组点，建议覆盖整个检测区域并增加点数。实际坐标应采用同一单位和坐标系。
2. 选择全部点拟合或 RANSAC，配置像素内点阈值、最低有效点比例和最大均方根误差。
3. 将 `calibration` 输出绑定至流程或全局变量。它包含变换矩阵、单位、有效图像区域、可选图像尺寸和拟合质量；不要仅复制矩阵而丢失单位及有效区域。
4. 添加“标定平面坐标与距离”，将“标定结果”绑定到该变量或已连接上游结果的 `calibration` 字段。
5. 测量点表填写原始图像像素坐标，按顺序计算相邻点距离。开启“连接末点与首点”后计算闭合周长，至少三个点。输出包括分段长度、方向、总长度及实际坐标明细。

没有图像时也能使用坐标表；有图像时检查点位边界并返回标注图。复用标定结果时应固定相机位置、焦距、拍摄平面和图像处理方式。有尺寸记录的标定拒绝不同图像尺寸，相同尺寸不能证明相机姿态、裁剪区域或成像条件未变化。

## 测量范围与质量

- 此模型只描述同一平面上的透视变换，不推断深度，不补偿镜头畸变，不进行相机内外参或手眼标定。应使用畸变可忽略或已正确去畸变的图像，保持标定和测量图像坐标一致。
- RANSAC 按“实际平面 → 图像”拟合，阈值和重投影误差统一为像素。输入点为浮点数不代表已实现亚像素定位或获得对应物理精度。
- 四点模型可精确拟合错误对应关系，低训练残差不等于精度验收；必须使用独立已知尺寸或验证点验证。重复点、共线/过窄分布、有效点不足、误差超限、奇异变换和跨越透视无穷线都会失败。
- 默认拒绝标定内点凸包之外的测量。显式允许外推后，结果标记 `extrapolated`，点表显示是否处于标定区；仍需独立验证区域外精度。
- 标定表允许 4–500 行；测量表允许 2–500 行。单位 mm/cm/m 表示输入数据的含义，修改单位名称不会自动缩放数值。闭合线段输出周长，不输出面积；点序由表格行顺序决定。
- 标定或测量失败时，本轮变量变更不会提交；服务器中旧标定变量可能仍存在，应查看本轮运行状态。

## 演示与验证

`scripts/generate-planar-samples.py` 生成已知 100×60 mm 平面及 60×30 mm 内矩形的透视图。三个演示验证 60 mm 线段、180 mm 周长，以及剔除一个错误对应点后仍能测得 60 mm。均为合成验证，不代表现场标定准确度。

运行 `.venv/Scripts/python.exe tests/test_planar.py`、`node --test tests/test_operator_plugins.cjs` 或 `npm test`。覆盖 8 项数值测试、表格参数类型/范围/格式校验、真实 Python 插件链路、HTTP 工程点表与标定变量保存及失败回滚。
