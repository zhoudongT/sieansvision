# 三维局部表面检测插件

`sieans-normals` 1.0.0 / API v1。使用已安装的 Open3D 0.20.0 与 NumPy。原始插件代码为 MIT；没有新增依赖。

## 使用

工具箱“扩展算子”选择“3D 法向与坡度检测”，输入 mm 或 m 点云。邻域半径、最少/最多邻居、参考方向、坡度/残差上限和允许不良比例均为参数表单。检测明细显示点索引、坐标、有效性、原因、法向 XYZ、坡度、局部拟合残差、表面变化率、超差状态。结果可绑定模块、流程、全局变量。

“演示案例 → 3D”提供合成 30° 斜面合格、坡度超差、邻域不足三个示例。合格点绿色、超差点红色、无效点灰色。原始点序、坐标、单位及坐标系不变；关闭着色时保留输入点云通道。此插件不会自动将法向替换为输入点云的几何坐标。

## 计算定义与限制

- 使用 Open3D KDTreeFlann 的混合邻域搜索（半径 + 最多点数），对邻域中心化协方差做对称特征分解，最小特征值对应的单位向量为法向。最少邻居包含自身；先去除重复坐标再建立邻域，重复原始点仍分别计入检测统计。
- 法向符号朝参考方向统一；坡度为无向夹角，范围 0–90°。它不区分物体内外侧，不等于全局曲面法向拓扑定向。
- 局部拟合残差为 `sqrt(最小特征值)`，即邻域各点到其最小二乘平面的 RMS，沿用点云单位。表面变化率为最小特征值/特征值之和，无量纲。这些值依赖采样密度、半径、噪声和曲率，不是标准粗糙度 Ra/Rz，不替代轮廓仪计量。
- 共线/重合邻域（第二特征值 ≤ 最大特征值的 1e-8）或法向不唯一（最小两特征值差 ≤ 最大特征值的 1e-6）标为无效。舍弃浮点舍入级最小特征值（≤ 64 个双精度机器 epsilon × 最大特征值）。邻域半径太小、点密度不足或边缘点可能无效，需要按真实采样设置。
- 无效比例的分母为总点数；超差比例的分母为有效点数。任一坡度/残差超过上限则超差。两种比例都满足设置并至少存在一个有效法向才通过。全部无效时不输出坡度/残差统计，不以零冒充测量值；`hasValidNormals=false`、`passed=false`。
- 支持 3–20000 个点，最多 256 个邻居；着色点云最多 10000 点，较大输入先下采样或关闭着色。统计覆盖所有输入点；明细最多 500 行，无效点、超差点优先并保留原始点索引。当前采用独立 Python 进程，30 秒超时；大点云实时性能及实机精度需另行验收。

## 来源和验证

- [Open3D GitHub](https://github.com/isl-org/Open3D)
- [官方法向估计说明](https://open3d.org/docs/release/tutorial/geometry/pointcloud.html)：局部协方差与方向歧义。插件显式实现退化检查，避免库默认法向掩盖无效邻域。
- [KDTreeFlann API](https://www.open3d.org/docs/latest/python_api/open3d.geometry.KDTreeFlann.html)

`python scripts/generate-normal-samples.py` 重建演示；`python tests/test_normals.py` 验证已知坡度、方向、阈值、单位、噪声、重复/稀疏/共线/各向同性邻域和显示上限。默认 `npm test` 还覆盖真实插件子进程、变量绑定、HTTP、颜色及工程往返保存。合成数据通过不代表工业/深度相机、现场零件或 Linux 已验收。
