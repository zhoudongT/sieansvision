# SIEANS 2D 定位跟随与多目标模板定位

0.3.0 开发源码新增 `sieans-fixture` 1.0.0（MIT），并扩展既有“模板与定位”。使用已安装的 OpenCV、NumPy 和 Pillow；不增加运行依赖。参数为表单、点位为两列表格，模型通过变量/上游结果绑定，结果为表格。0.2.0 已发布包不变。

## 多目标定位

原有平移、旋转和缩放搜索继续使用 OpenCV 的掩膜归一化平方差，匹配分数为 `1 − 归一化平方差`，裁到 0–1。该分数不是概率，也不是亮度不变或形状不变匹配。模板上传及框选入口沿用原工作台，参考图随工程保存。

新增“最多目标数”和“去重重叠比例”表单。各旋转/缩放候选按分数排序，用**旋转四边形的 IoU** 去重，避免同一目标以邻近角度/比例重复计数。最多返回 50 个目标。位置和角度来自离散搜索，不能声称亚像素模板定位；缩放为均匀比例，正角沿用 OpenCV 的逆时针方向（图像 Y 向下）。对称物体不能可靠区分方向，不支持透视变化、遮挡鲁棒性或任意形状匹配。

结果包括 `found`、`count`、`items`、`bestScore`、`unique`、`limitReached`、候选受限状态、组合数及诊断。每个目标在明细表中保留分数、中心、角度、比例、四边形、偏移及位姿。根层保留最佳目标的位置等字段，并新增 `pose`；便于旧工程继续读取最佳匹配。多目标时根层最佳不等于唯一，设备动作或检测跟随前应明确选择目标或以 `unique` 条件保护。

没有达到阈值时只返回状态、分数和空目标表，**不再返回未检出目标的中心/角度/位姿**。原来在未找到时仍读取位置的工程需要先接条件判断；直接引用缺少字段会失败并回滚该轮变量。未找到不是引擎错误；Node-RED 节点显示黄色“未检出目标”。

`unique=true` 要求只选中一个目标且结果未受上限影响。达到返回上限且仍有独立候选、或每组合候选被截断时，`limitReached=true` 且 `unique=false`。返回数量在这种情况下不是完整数量，不能当作总工件数；调整 ROI、阈值、角度/比例或最大目标数后重试。去重阈值过低会合并相邻目标，过高会保留重复目标，应通过实际样本设置。

模板至少 4×4、最多 100 万像素；搜索 ROI 最多 400 万像素；比例表 1–8 行，比例 0.1–5；角度步长 1–180°。预估旋转×比例不超过 256 组合、累计响应位置不超过 3000 万，超限先报错；全局候选超过 4096 也报错，不无限运算。每组合保留有界局部峰，过多时明确标记受限。

## 位姿契约与点位转换

`sieans-pose2d-v1` 包含原图/模板尺寸及解码后 BGR 像素摘要、均匀比例、角度、模板像素→原图像素 2×3 矩阵及逆矩阵。模板中心为 `((宽−1)/2, (高−1)/2)`；输出 ROI 的坐标偏移已经计入位姿。无需在下游再次加 ROI 左上角。

“定位跟随 · 点位转换”接受该位姿，以及 X/Y 点位表，支持模板→图像或图像→模板。每行显示输入/输出像素坐标、目标范围状态；超出范围时不裁剪坐标，`passed=false`。模板外的点位可用于周边检测区域规划，但不保证映射后仍在图内。最多 1000 行。

若流程仍持有图像，会验证该图像与位姿属于同一帧内容；不匹配时拒绝使用旧位姿。没有输入图像时可离线转换点位，但无法验证当前帧。摘要只防止意外混帧，不证明相机时序、实物身份或模型真实性。

## 检测图像校正

“定位跟随 · 图像校正”将当前原图按位姿映射到模板像素坐标；可配置模板坐标中的 X、Y、宽、高。宽/高为 0 时使用模板对应尺寸。检测区域可在模板周边，但四个采样角点必须都在原图内；超出时直接报错，不能用边界补黑冒充缺陷。

输出为无损 PNG，既作为显示图，也作为**后续算子的处理图像**；原图不再是这个分支的处理坐标系。后续点位从校正区域左上角开始，想回到模板坐标需要加上本步 `templateOriginX/Y`。原图坐标可用前述位姿继续转换。图像校正后不能再把原位姿当作新图像的同帧位姿使用。

校正单边不超过 2048、面积不超过 400 万像素，PNG 不超过约 700 KB；超出时缩小检测区。采样为双线性插值，会影响边缘与灰度，特别是缩小后再放大；不能用插值替代真实光学分辨率或尺寸标定。不支持透视、非均匀缩放、反射或畸变校正，位姿中旋转/比例/正反矩阵不一致会拒绝。

## 五个演示

在“演示案例 → 定位”中提供：

1. 三目标旋转/缩放去重，目标明细表。
2. 唯一旋转目标上的圆孔/方孔点位转换。
3. 定位→校正 56×40 ROI→真实灰度分析，两孔检测。
4. 空图未检出诊断，不输出伪造位置。
5. 唯一目标条件保护：空图或多目标时跳过下游，换单目标图时才校正检测。

每例带图像和表格运行画面。合成素材由 `scripts/generate-fixture-samples.py` 生成，不代表真实工件精度。运行 `npm run test:fixture` 验证多目标、NMS、ROI 偏移、点位正反转换、校正检测、资源边界、同帧校验、变量回滚、Node-RED、条件保护与 HTTP 保存/重启。
